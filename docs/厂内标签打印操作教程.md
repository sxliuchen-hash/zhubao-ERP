# 厂内标签打印操作教程

这份教程只讲怎么把标签送到一台 Windows 电脑的打印机。程序是 `print-agent/ZhubaoPrintReceiver.exe`。它和网页上的「浏览器预览打印」是两条路：浏览器打印弹的是你自己电脑的打印窗口；厂内打印是网页把任务交给服务器，再由接了打印机的那台电脑领走。

当前试用地址是 `https://106.55.226.166`。你平时登录的地址如果不是这个，配置里的 `baseUrl` 改成浏览器地址栏里的地址，并且必须以 `https://` 开头。

佳博标签机出纸、纸张间隙和扫码还没有在现场验收。窗口里出现「已送入系统队列」只说明 Windows 接到了任务，还要看打印机有没有吐纸。

## 先分清两个人

**管理员**在网页上建立工位和队列，并抄下只显示一次的凭据。

**打印电脑**上放接收程序和配置文件，程序一直开着，负责把任务送进本机打印机。

能在「来料与订单 → 标签」里生成并提交的，是管理员、总经理、收货员、仓管，以及勾了「标签打印」顶岗的业务管理。页面最下面的「工位与打印队列」只有管理员看得到。

## 1. 管理员保存工位

1. 用管理员账号登录。
2. 打开左侧 **来料与订单 → 标签**。
3. 滚到 **工位与打印队列**。
4. 工位 ID、工位名称都填 `liuchen`。勾选「启用工位」。页面若已经写好 `liuchen`，不用再改。
5. 点 **保存工位**。
6. 页面出现一行：**新工位凭据（仅此时显示）**，后面是一长串以 `PS-` 开头的文字。马上复制到记事本。关掉页面或再点一次保存，这串字不会再出现。
7. 若已经保存过、凭据没抄下来：在该工位那一行点 **轮换凭据**，用新出现的那串替换旧的。旧凭据立刻失效。

再点「编辑」或再次「保存工位」不会发新凭据。

## 2. 管理员保存队列

工位保存成功后，同一块区域往下：

| 填写项 | 填什么 |
|---|---|
| 所属工位 | `liuchen` |
| 队列 ID | `liuchen` |
| 显示名称 | `liuchen` |
| 标签类型 | 母单与子单 |
| 宽 / 高 | `40` 和 `30` |
| 启用队列 | 勾上 |

点 **保存队列**。下面应出现一行：`liuchen / liuchen · liuchen · 启用`。

队列的宽高必须和标签纸一致。现在内置模板是 40×30 毫米。类型选「母单」时，子单标签选不到这个队列；选「子单」时，母单标签选不到。

## 3. 在打印电脑上改配置

程序只读和它放在同一个文件夹里的 **`print-agent.properties`**。`config.example.properties` 是空白样子，改它不会生效。

本仓库里这两份文件的位置：

- 程序：`print-agent/ZhubaoPrintReceiver.exe`
- 要改的配置：`print-agent/print-agent.properties`

若你把 exe 拷到了别的文件夹，配置必须跟那一份 exe 放在一起。仓库里这份配置不会跟着走。

用记事本打开 `print-agent.properties`，改成类似这样（凭据和打印机名称换成你自己的）：

```properties
baseUrl=https://106.55.226.166
stationId=liuchen
token=这里粘贴网页上那串 PS- 开头的凭据
queue.liuchen=这里填写 Windows 打印机的全名
# 打开网页提示证书不受信任时，去掉下一行开头的 #
# allowUntrustedCertificate=true
```

对应关系：

- `stationId` 等于网页上的工位 ID。
- `token` 等于刚才复制的凭据，不要加引号，不要留「请换成工位凭据」。
- `queue.` 后面的字等于网页上的队列 ID。现在两边都是 `liuchen`，所以这一行必须写成 `queue.liuchen=`。
- 等号右边是 **这台电脑**「设置 → 打印机和扫描仪」里的打印机全名，一个字都不能差。大小写可以不同。

这台开发电脑上目前能看到的名称是：

- `导出为WPS PDF`
- `Pantum M7160DW Series 5F1D37`
- `Microsoft Print to PDF`
- `Fax`

这里没有标签机。要先把整条链路走通，等号右边可以暂时写成 `Microsoft Print to PDF`，任务会进 PDF 打印机。要打标签纸，把 exe 和这份配置一起拷到接了标签机的电脑，再把等号右边改成那台机器上的打印机全名。

同一工位不要再开 Java 打印程序。两台程序会抢同一批任务。

保存配置。这个文件里有凭据，不要发给别人，也不要提交到 Git。

## 4. 启动接收程序

1. 若还有一个黑窗口停在「按回车关闭窗口」，先按回车关掉。那个窗口还占着程序时，不能换新版本。
2. 双击旁边的 `ZhubaoPrintReceiver.exe`。程序启动时会向 `baseUrl` 询问 `/downloads/print-agent.json`。服务器上有更新的版本时，它会自己下载并重新打开，不用再手工拷贝 exe。配置文件留在原处。下载失败就继续用当前程序。
3. 正常时应看到：
   - `打印接收已启动：liuchen`
   - 几行 `本机打印队列：……`
   - 窗口留着不关。没有新任务时它不会一直刷字，大约每 3 秒问一次服务器。

按用途看窗口上的字：

| 窗口上的字 | 接着做什么 |
|---|---|
| 缺少配置文件 | 确认 `print-agent.properties` 和你双击的那个 exe 在同一文件夹，然后重新双击 |
| 本机没有队列 liuchen 对应的打印机 | 把 `queue.liuchen=` 右边改成窗口里「本机打印队列」列出的某一个全名 |
| 配置的打印机在本机都不存在 | 同上。这时程序还没有向服务器领任务 |
| 工位凭据无效 | 核对 `stationId` 和 `token`。对不上就在网页上点「轮换凭据」，把新凭据贴进配置后再开程序 |
| 服务器关闭了本应保持活动状态的连接 | 这是旧程序复用了已被服务器关掉的连接。关掉黑窗口，换成新的 `ZhubaoPrintReceiver.exe` 后再双击。配置文件不用改 |
| 已按配置忽略 HTTPS 证书校验 | 仅测试地址需要。正式环境把 `allowUntrustedCertificate` 那行重新用 `#` 注释掉 |
| 已领取 …… | 程序拿到一张标签，正在送给打印机 |
| 已送入系统队列 | Windows 已接到。打开打印机队列或看标签机是否出纸 |
| 发送前失败 | 看后面的原因。到网页上刷新该任务状态 |
| 保存标识载荷无效，不能省略打印 | 这是旧接收程序读错了保存要求。关掉黑窗口，换成新的 `ZhubaoPrintReceiver.exe` 后再提交一张。刚才失败的那张不会自动重打 |
| 打出来明显大于 40×30 | 网页任务已经是 40×30。旧接收程序按打印机点数放大了画面。关掉黑窗口，换成新的 `ZhubaoPrintReceiver.exe` 后再打一张。打印机驱动里的标签纸也要选 40×30 |
| 工位打出来的格式和浏览器不一样 | 40×30 按浏览器紧凑版式：顶栏是类型和单号，二维码靠左，字段自动换行。更大的纸按浏览器普通版式：二维码在左，品牌和字段在右。旧程序不是这套排版。换成带云更新的 `ZhubaoPrintReceiver.exe` 后，以后程序会自己向服务器要新版本 |

打不开网页、证书报错时，在配置里写成：

```properties
allowUntrustedCertificate=true
```

保存后再开程序。

## 5. 提交一张标签

接收程序保持开着。换一个能打印的账号（管理员也可以）：

1. 打开 **来料与订单 → 标签**。
2. 在「按母单号便捷生成」里填已有母单号，点 **按母单生成**。或在上面填主编码后点 **生成标签预览**。
3. 预览出现后，在「选择工位和打印队列」里勾选 `liuchen · liuchen（liuchen）`。
4. 每目标份数填 `1`。
5. 点 **提交到打印工位**。
6. 点 **刷新目标状态**。

状态对照：

| 页面上的状态 | 含义 |
|---|---|
| 待工位上线或领取 | 任务在服务器上，接收程序还没领走。看打印电脑的窗口是否还开着、凭据是否正确 |
| 已领取 | 程序已拿走，正在画图或送打印机 |
| 已送入系统队列 | 已交给 Windows。再看打印机或标签机 |
| 失败 | 没送进打印机。页面写明原因，点取消后可以再提交 |
| 不确定是否出纸 | 程序领走后没有及时回报。先看打印机里有没有这张，再在页面上选核纸结果 |
| 已取消 | 这张不再打印 |

「浏览器预览打印」不会走到这台接收程序。

勾选框是空的、并写着「暂无匹配当前标签类型和纸张尺寸的队列」时，回到第 2 步：队列要启用，纸张要是 40×30，类型要盖得住这张标签（母单与子单，或与这张标签相同的类型）。

## 6. 换打印机或换电脑

- 换打印机：改 `queue.liuchen=` 右边的全名，关掉黑窗口，再双击 exe。网页上的工位和队列不用重建。
- 换一台打印电脑：复制 `ZhubaoPrintReceiver.exe` 和 `print-agent.properties` 到新电脑的同一个文件夹，把打印机全名改成新电脑上的名称。两台电脑不要用同一工位同时开着。
- 凭据怀疑泄露：管理员点 **轮换凭据**，把新凭据写入配置，再重新打开程序。

打印过的画面会留在配置文件旁边的 `received` 文件夹，里面有对应任务的 json 和 png，便于核对二维码和文字。
