# 需向客户展示的内容清单

**日期**：2026-07-09
**目的**：客户现在还想象不出系统的效果、会产生什么、怎么串起来。这份清单列出**该主动展示给客户看的东西**，让客户在确认字段和规则前，先看到"实物长什么样"，才能提出有价值的意见。

| 优先级 | 含义 |

| ⭐⭐⭐ | 客户最直观、最该先看，决定他对系统的第一印象 |
| ⭐⭐ | 帮助客户理解流程和单据 |

## 二、展示内容清单

### A. 实物标签样张 ⭐⭐⭐（已做，见 output/样张/母单标签样张.html）

- **母单标签**：贴周转盒/周转袋上，含母单号、二维码、客户、物料、数量、重量、当前工序等
- 让客户确认：**标签上要放哪些信息**（周转盒场景要不要件数/重量/负责人/进度）
- 待补样张：子工单标签、出货标签、返工标签

### B. 全链路追溯效果 ⭐⭐⭐（系统已有数据支撑，需做展示页/截图）

- 扫一个母单二维码 → 调出这批料从**收货到出货的完整经过**：
  收货签收 → 拆包称重 → 拆成几个子工单 → 每道工序谁做的/做了多少/损耗多少 → 质检结果 → 入库 → 出货快递单号
- 这是系统最核心的卖点，要让客户"扫一下就看到一条料的一生"

### C. 单据流转关系图 ⭐⭐⭐（需做一张图）

- 一张图说清：**哪些单据跟着订单走、哪些跟着母单走、哪些跟着子工单走**
- 订单 → 母单（1 对多）→ 子工单（1 对多）→ 报工/质检/损耗 → 出库单 → 快递
- 让客户明白"东西是怎么串起来的、不会乱"

### D. 各角色看到的界面 ⭐⭐（系统已有页面，需截图/演示）

- 老板/管理：今日收发货、在制、待审批、损耗异常一屏看全
- 收货员：待入库、待称重
- 车间组长：待拆分、待派工、加工中
- 操作工（手机）：我的待办、扫码报工
- 质检员：待质检、缺陷录入
- 库管：待出货、库存
- 让客户看到"每个岗位打开系统看到的是他关心的东西"

### E. 手机扫码报工演示 ⭐⭐（系统已有 PWA）

- 工人手机扫子工单码 → 自动带出当前工序 → 填数量/重量 → 提交
- 强调：**一期先用手机扫码**，扫码枪到货再接；操作 3 步内完成

### F. 损耗与工资试算效果 ⭐⭐（系统已有，需展示）

- 输入投入/产出重量 → 系统算出损耗、是否超标、计件工资试算
- 强调：一期**只试算参考、不真发/不真扣**，让客户放心先用起来

### G. 数据看板 / 报表 ⭐（可后续）

- 产量、损耗、库存、工资试算的汇总报表

---

## 三、建议的展示顺序（给客户演示时）

1. 先看 **B 全链路追溯**（震撼点：扫码看一条料的一生）
2. 再看 **A 标签样张**（实物感：贴盒子上就这样）
3. 然后 **C 单据流转图**（讲清楚不会乱）
4. 再按角色看 **D 界面** + **E 手机报工**（每个岗位怎么用）
5. 最后 **F 损耗工资试算**（打消"会不会乱扣钱"的顾虑）
