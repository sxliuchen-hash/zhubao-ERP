# 需向客户展示的内容清单

**日期**：2026-07-09
**目的**：客户现在还想象不出系统的效果、会产生什么、怎么串起来。这份清单列出**该主动展示给客户看的东西**，让客户在确认字段和规则前，先看到"实物长什么样"，才能提出有价值的意见。

---

## 一、优先级说明

| 优先级 | 含义 |
|---|---|
| ⭐⭐⭐ | 客户最直观、最该先看，决定他对系统的第一印象 |
| ⭐⭐ | 帮助客户理解流程和单据 |
| ⭐ | 锦上添花，可后续补 |

---

## 二、展示内容清单

### A. 实物标签样张 ⭐⭐⭐（已做，见 docs/samples/母单标签样张.html）

- **母单标签**：贴周转盒/周转袋上，含母单号、二维码、客户、物料、数量、重量、日期等**固定信息**
- **重要设计原则**：标签打印一次贴上去不再变，**只印固定不变的信息**；加工进度/当前工序这类会变的信息**不印在标签上**，工人**手机扫码看实时最新工序**，既准确又省纸（不反复打印）。样张右侧已画出"扫码后手机看到的实时进度"示意。
- 让客户确认：**标签上要放哪些固定信息**（周转盒场景要不要件数/重量/负责人/子工单号）
- ✅ 已补齐整套标签样张：子工单标签、出货标签、返工标签（见 docs/samples/子工单与出货标签样张.html）

### B. 全链路追溯效果 ⭐⭐⭐（已做展示样张，见 docs/samples/全链路追溯展示.html）

- 扫一个母单二维码 → 调出这批料从**收货到出货的完整经过**：
  收货签收 → 拆包称重 → 拆成几个子工单 → 每道工序谁做的/做了多少/损耗多少 → 质检结果 → 入库 → 出货快递单号
- 这是系统最核心的卖点，"扫一下就看到一条料的一生"
- 样张含：母单概览、加工时间线、子工单明细、库存台账、证据链。真实数据由系统自动生成，此为效果展示。

### C. 单据流转关系图 ⭐⭐⭐（需做一张图）

- 一张图说清：**哪些单据跟着订单走、哪些跟着母单走、哪些跟着子工单走**
- 订单 → 母单（1 对多）→ 子工单（1 对多）→ 报工/质检/损耗 → 出库单 → 快递
- 让客户明白"东西是怎么串起来的、不会乱"

### D. 各角色看到的界面 ⭐⭐（已做，见 docs/samples/各角色界面一览样张.html）

- 一张图展示老板/收货员/车间组长/操作工/质检员/库管各自打开系统看到的内容和数据范围
- 让客户看到"每个岗位打开系统看到的是他关心的东西，不会看错看乱"

### E. 手机扫码报工演示 ⭐⭐（已做，见 docs/samples/手机扫码报工流程样张.html）

- 3 步流程图：扫码 → 填数量重量 → 提交完成，含"为什么工人愿意用"说明
- 强调：**一期先用手机扫码**，扫码枪到货再接；操作 3 步内完成

### E2. 老板首页看板 ⭐⭐⭐（已做，见 docs/samples/老板首页看板样张.html）

- 老板打开系统第一眼：今日收发货、在制、待处理异常、损耗/工资试算概览，一屏看全
- 给决策人看的，最能体现"上系统后我能省心管全局"

### F. 损耗与工资试算效果 ⭐⭐（已做，见 docs/samples/损耗与工资试算样张.html）

- 损耗按工序自动算、超标提醒；计件工资自动试算，返工不计
- 醒目强调：一期**只试算参考、不真发/不真扣**，让客户放心先用起来

### G. 一页纸系统价值介绍 ⭐（已做，见 docs/samples/一页纸系统价值介绍.html）

- 大白话讲"现在的烦恼 + 这系统解决什么 + 怎么开始"，适合正式演示前发微信群/朋友圈预热

---

## 三、建议的展示顺序（给客户演示时）

1. 先看 **B 全链路追溯**（震撼点：扫码看一条料的一生）
2. 再看 **A 标签样张**（实物感：贴盒子上就这样）
3. 然后 **C 单据流转图**（讲清楚不会乱）
4. 再按角色看 **D 界面** + **E 手机报工**（每个岗位怎么用）
5. 最后 **F 损耗工资试算**（打消"会不会乱扣钱"的顾虑）
