# 现场登记表字段差异分析与补齐方案

**文档版本**：V1.0  
**更新日期**：2026-07-07  
**来源文件**：

- `入库登记表.xlsx`
- `出货登记表.xlsx`
- `抛光登记表.xlsx`
- `雕刻登记表.xlsx`

---

## 1. 结论

这 4 张现场登记表说明当前系统大流程方向是对的，但字段粒度还不够现场化。

已覆盖：

- 入库、拆包、生成母单、库存台账。
- 工序报工、称重交接、质检返工。
- 成品出库、快递信息、追溯。
- 抛光作为工序已存在。

需要补齐：

- 入库签收字段：入库日期、快递名称、寄货人姓名、收货人姓名、拆箱签字、货品名称、备注。
- 出货登记字段：交货日期、客户、交货类目、交货数量、快递、经办人、备注。
- 抛光日记录字段：姓名、日期、工作项目、开始时间、完成时间、完成情况、交单审核、备注。
- 雕刻设备统计字段：日期、客户、品类、机器编号、雕刻数量、操机签字、备注。
- 工序配置：必须把 `雕刻` 纳入一期工序模板；`抛光` 需要支持按人、按日、按工作项目和审核状态统计。

## 2. 原始表字段

### 2.1 签收入库登记表

| 原表字段 | 系统字段建议 | 当前覆盖 | 补齐方式 |
|---|---|---|---|
| 序号 | display_sequence / line_no | 部分 | 页面显示字段，不作为业务主键 |
| 入库日期 | inbound_date | 缺失 | 增加到母单/入库登记字段 |
| 快递名称 | express_company | 缺失 | 增加入库快递公司字段 |
| 快递单号 | inbound_express_no / courierNo | 已覆盖 | 保持唯一校验 |
| 寄货人姓名 | sender_name | 缺失 | 增加入库寄件人快照 |
| 收货人姓名 | receiver_name | 缺失 | 增加入库收货人快照 |
| 拆箱签字 | unpack_signer | 缺失 | 增加拆箱签字/确认人字段，支持签名附件 |
| 货品名称 | goods_name_snapshot / material_name | 部分 | 作为来料货品名称快照，后续再匹配物料档案 |
| 数量 | quantity | 已覆盖 | 保留数量单位 |
| 备注 | inbound_remark | 部分 | 增加入库备注字段 |

### 2.2 交货情况登记表

| 原表字段 | 系统字段建议 | 当前覆盖 | 补齐方式 |

| 日期 | delivery_date / shipped_at | 部分 | 出货单增加交货日期 |

| 原表字段 | 系统字段建议 | 当前覆盖 | 补齐方式 |

| 姓名 | employee_id / employee_name_snapshot | 已覆盖 | 报工员工 |

| 原表字段 | 系统字段建议 | 当前覆盖 | 补齐方式 |

## 3. 工序补齐

一期工序模板至少应包含：

| 工序 | 是否已有 | 补齐要求 |
|---|---|---|
| 收货/签收 | 部分 | 作为入库登记动作，不计工资，不生成生产工序 |
| 拆包称重 | 已有 | 增加拆箱签字、寄收件人和快递公司 |
| 雕刻 | 缺失 | 增加机器编号、品类、操机签字、设备产量统计 |
| 抛光 | 已有 | 增加员工日记录、开始/完成时间、完成情况和交单审核 |
| 镶石/焊接/打磨/清洗 | 已有或部分 | 继续按工序报工和质检规则处理 |
| 终检入库 | 已有 | 终检通过后转成品库存 |
| 打包出货 | 部分 | 增加交货类目、经办人、交货数量和快递公司 |

## 4. 建模建议

### 4.1 不建议把 Excel 原表照搬成业务表

这些 Excel 是现场登记习惯，不是最终领域模型。系统应吸收字段，但不要把系统设计成 4 张孤立登记表。建议：

- 入库登记字段合并到母单/入库签收记录。
- 抛光登记字段合并到报工记录和工序日记录。
- 雕刻统计字段作为设备产量记录，并关联工序报工。
- 出货登记字段合并到出库单和出库明细。

### 4.2 建议新增或扩展对象

| 对象 | 目的 |
|---|---|
| `biz_inbound_receipt` 或扩展 `biz_mother_order` | 保存入库签收、快递、寄收件人、拆箱签字 |
| `biz_work_report` 扩展 | 保存工作项目、开始/完成时间、完成情况、交单审核 |
| `biz_machine_output_record` | 保存雕刻机每日产量、机器编号、操机签字 |
| `biz_outbound_order` 扩展 | 保存交货类目、经办人、交货日期、备注 |

## 5. 验收用例补充

1. 入库登记：录入快递名称、快递单号、寄货人、收货人、拆箱签字、货品名称和数量后，系统生成母单并能在追溯链查看这些字段。
2. 抛光日报工：操作工选择抛光工作项目，填写开始/完成时间、完成情况，提交后进入交单审核。
3. 雕刻统计：同一客户同一天可按 1-8 号机器录入雕刻数量，并按机器编号统计产能。
4. 出货登记：选择客户和交货类目，录入交货数量、快递、经办人后确认出货，库存台账转为已发货。
5. 追溯查询：按快递单号、母单、工单、机器编号或经办人查询时，能关联到入库、工序、设备产量、出货和证据链。

## 6. 当前缺口处理优先级

| 优先级 | 缺口 | 原因 |
|---|---|---|
| P0 | 入库签收字段、出货经办字段 | 影响客户来料/交货追溯和责任确认 |
| P0 | 雕刻工序和机器编号 | 现场已有独立登记表，说明这是实际生产节点 |
| P1 | 抛光工作项目和交单审核 | 影响员工日报、计件试算和责任确认 |
| P1 | 操机签字/拆箱签字电子化 | 一期可先用姓名快照，二期接签名图片 |
| P2 | Excel 批量导入 | 一期可先手工录入，试点稳定后再做导入 |
