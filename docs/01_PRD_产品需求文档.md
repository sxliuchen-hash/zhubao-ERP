## 1. 产品定位

本系统面向客户来料加工业务，覆盖来料收货、拆包称重、母单建档、子工单拆分、工序报工、质检返工、库存台账、成品出库、视频证据、全链路追溯和计件工资试算。

系统不是普通进销存，也不是完整财务 ERP。它的核心是以“客户来料批次”为中心，建立可追溯、可核对、可解释的加工管理闭环。

### 1.1 业务痛点

- 客户来料、半成品、成品、返工品、报废品状态不清，账实难核对。
- 贵重物料损耗缺少按工序、员工、称重交接和证据链的解释。
- 纸质工单流转慢，生产进度无法实时掌握。
- 质检不合格、返工、报废缺少统一流程和责任归因。
- 拆包和打包视频虽然存在，但难以和业务单据自动关联。
- 计件工资依赖人工统计，容易漏算、错算、争议大。

### 1.2 建设目标

| 目标 | 说明 |
|---|---|
| 全链路追溯 | 母单、子工单、工序、质检、返工、损耗、库存、出库、视频可串联查询 |
| 库存可核对 | 所有库存变化均由业务单据驱动，生成库存台账 |
| 损耗可解释 | 损耗按工序投入重量计算，并关联称重交接、责任归因和审批 |
| 作业可扫码 | 现场通过 PWA 移动网页或扫码枪完成报工、质检和查询 |
| 工资可试算 | 按报工记录和单价快照生成工资试算，不在一期正式发薪 |
| 证据可留存 | 拆包、打包、异常处理支持视频或附件证据 |
| 权限可隔离 | 不同岗位按角色和数据范围访问系统 |

## 2. 分期范围

### 2.1 一期范围：核心闭环可运行

一期目标是替代手工台账，跑通真实业务链路。

一期必须包含：

- 基础档案：客户、物料、工序、工序模板、员工、仓库、计件单价、损耗率。
- 客户订单：订单建档、订单状态、关联母单和出库。
- 来料入库：扫码收货、拆包登记、称重、母单生成、客户所有库存入账。
- 标签打印：母单标签、子工单标签、出库标签。
- 生产工单：母单拆分子工单、工序实例生成、分配、扫码报工。
- 称重交接：关键工序记录投入重量、产出重量、交接人和证据。
- 质检返工：质检合格、不合格、返工、报废、让步通过、复检。
- 损耗管理：按工序计算损耗，超标损耗触发轻量审批。
- 库存管理：库存台账、库存余额、库存冻结、库存调整。
- 出库管理：成品选择、冻结库存、打包称重、发货扣库存。
- 全链路追溯：按母单、子工单、快递单号、客户查询时间线。
- 工资试算：按报工记录和单价快照生成试算明细和导出。
- PWA 移动网页：扫码、报工、质检、库存查询。
- 视频证据：拆包和打包半自动截取，失败允许人工上传。
- 轻量审批：来料异常、损耗超标、返工超次数、报废、库存调整。

### 2.2 一期明确不做

以下事项不进入一期主验收：

- 正式工资发放、工资锁账和工资扣款。
- 完整财务核算、成本会计、总账、应收应付。
- 完整工作流引擎和复杂审批流编排。
- 原生 Android App。
- 电子秤自动采集强集成。
- 完整库存盘点审核。
- 复杂 BI 大屏和经营分析。
- 客户门户、小程序、外部客户协同。
- 快递、短信、财务软件、人脸门禁等外部系统正式集成。

### 2.3 二期范围：效率和管理增强

- 电子秤自动采集和设备绑定。
- 完整盘点、盘亏盘盈审批。
- 正式工资结算、锁账、调整和工资扣减审批。
- 更完整的返工、报废、退货流程。
- 复杂审批流和流程引擎。
- Android 原生或专用 PDA 支持。
- 高级报表、异常预警和经营看板。

### 2.4 三期范围：外部协同和智能化

- 客户查询门户。
- 快递、短信、财务系统集成。
- AI 视频辅助识别、损耗异常预警。
- 多工厂、多组织、多租户。

## 3. 角色与权限

| 角色 | 核心诉求 | 一期功能 |
|---|---|---|
| 总经理/负责人 | 查看关键数据，审批异常 | 首页看板、审批、追溯、报表 |
| 业务员/客服 | 录入客户订单，跟进交付 | 客户订单、进度查询、出库状态 |
| 收货员 | 收货、拆包、称重、标签 | 来料入库、母单标签、拆包视频 |
| 车间组长 | 拆分工单、安排生产、处理异常 | 工单拆分、分配、返工处理 |
| 操作工 | 扫码领取任务，完成报工 | PWA 扫码、报工、我的任务 |
| 质检员 | 判断质量，发起返工/报废 | 待质检、质检操作、复检 |
| 库管员 | 管理库存和出库 | 库存查询、出库、打包、发货 |
| 财务/统计 | 复核工资和报表 | 工资试算、产量报表、损耗报表 |
| 系统管理员 | 用户、权限、配置 | 权限、参数、字典、日志 |

权限模型采用 RBAC + 数据范围：

- 功能权限控制页面、按钮、导入导出和敏感操作。
- 数据范围支持本人、本班组、本部门、全部、自定义客户范围。
- 敏感操作必须写入操作日志。

## 4. 核心业务闭环

一期主链路：

1. 创建客户和客户订单。
2. 收到客户来料，扫描快递单号。
3. 拆包、称重、拍照或记录视频时间。
4. 确认来料信息，生成母单和母单标签。
5. 生成客户所有的待加工库存。
6. 车间组长将母单拆分为多个子工单。
7. 系统按工序模板生成工序实例。
8. 打印子工单标签并分配给员工或工位。
9. 操作工扫码报工，记录数量、重量、损耗。
10. 关键工序记录称重交接。
11. 需要质检的工序进入待质检。
12. 质检合格进入下一工序或成品库存。
13. 质检不合格生成返工、报废或让步通过。
14. 超标损耗自动生成审批。
15. 成品入库后创建出库单并冻结库存。
16. 打包称重，关联打包视频。
17. 录入快递信息，确认发货并扣减库存。
18. 通过母单、子工单或快递单号查询完整追溯。
19. 导出产量、损耗、库存、工资试算报表。

## 5. 功能模块

### 5.1 首页工作台

- 展示待处理数量：待入库、待拆分、待报工、待质检、待审批、待出库、视频失败。
- 展示关键指标：在制工单、今日产量、超标损耗、库存异常、返工数量。
- 按角色展示不同入口。

### 5.2 基础档案

- 客户档案：客户编号、名称、联系人、结算规则、数据权限范围。
- 物料档案：物料编码、名称、规格、计量单位、重量单位、是否贵重、损耗计价单位、当前单价。
- 物料价格历史：价格生效时间、失效时间、变更原因。
- 工序档案：工序编码、名称、是否计件、计件单价、是否记录损耗、标准损耗率、是否质检。
- 工序模板：多道工序排序、默认质检节点、默认损耗设置。
- 员工档案：所属部门/班组、可操作工序、是否启用。
- 仓库档案：待加工、在制、半成品、成品、冻结、返工、报废、已发货。

### 5.3 客户订单

- 支持创建、编辑、提交、作废。
- 支持关联多个母单和多个出库单。
- 状态包含草稿、已确认、部分入库、生产中、部分发货、已完成、已作废。

### 5.4 来料入库与母单

- 扫描或录入快递单号。
- 登记客户、物料、数量、重量、照片、备注。
- 拆包开始和结束时间可触发视频截取任务。
- 确认入库后生成母单编码和客户所有库存。
- 异常来料需发起审批或标记待确认。

### 5.5 生产工单

- 支持按数量、重量或组合方式拆分子工单。
- 拆分总量不得超过母单可分配余额。
- 子工单生成后自动带出工序实例和单价/损耗率快照。
- 支持分配给员工、班组或工位。
- 报工必须按工序顺序执行，跳工序需权限。

### 5.6 PWA 移动作业端

- 手机浏览器访问，无需原生 App。
- 支持扫码识别母单、子工单、出库单。
- 操作工可查看我的任务、扫码报工、录入数量/重量/损耗。
- 质检员可查看待质检、扫码质检、发起返工/报废。
- 库管员可扫码查询库存和出库状态。

### 5.7 质检与返工

- 质检结果：合格、返工、报废、让步通过。
- 返工作为特殊工单类型处理，关联原工单、原工序和质检记录。
- 返工报工默认不计工资。
- 返工完成后必须复检或按规则关闭。
- 报废必须记录原因、责任归因和库存影响。

### 5.8 损耗管理

损耗按工序投入计算：

```text
本工序损耗重量 = 本工序投入重量 - 本工序产出重量 - 合理转移重量
允许损耗重量 = 本工序投入重量 × 标准损耗率
超标损耗重量 = max(0, 本工序损耗重量 - 允许损耗重量)
超标损耗金额 = 超标损耗重量 × 物料单价快照
```

一期只统计理论扣减金额，不实际扣工资。

### 5.9 库存管理

- 库存以客户、所有权、母单、子工单、物料、仓库、库存状态为核心维度。
- 所有库存变化必须生成库存台账。
- 库存余额由台账汇总或同步更新得出，不允许手工直接修改。
- 出库单创建后冻结库存，确认发货后扣减库存。
- 库存调整必须填写原因并审批。

### 5.10 出库管理

- 支持按客户、订单、母单、子工单选择成品。
- 创建出库单时冻结可用库存。
- 打包称重时记录重量、包装信息和视频时间。
- 录入快递单号后确认发货。
- 发货确认后扣减库存并更新订单状态。

### 5.11 全链路追溯

查询入口：

- 母单编码。
- 子工单编码。
- 客户订单号。
- 入库快递单号。
- 出库快递单号。
- 二维码扫码。

追溯内容：

- 客户订单、来料记录、母单信息。
- 拆包照片/视频。
- 子工单、工序、报工、称重交接。
- 质检、返工、报废。
- 损耗记录和审批。
- 库存台账。
- 出库、打包视频、快递信息。
- 操作日志。

### 5.12 工资试算

- 数据来源为报工记录。
- 工序单价在工序实例创建时保存快照。
- 正常报工按合格数量计算。
- 返工报工默认金额为 0。
- 损耗扣减仅展示理论扣减，不进入正式工资。
- 支持按员工、班组、日期、工序导出。

## 6. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 一期支持 50 人同时在线，常用列表 3 秒内响应 |
| 可用性 | 支持弱网重试，PWA 表单提交失败不丢失当前录入 |
| 安全 | 登录鉴权、角色权限、数据范围、敏感操作二次确认 |
| 审计 | 单据作废、库存调整、报工修改、视频替换、标签补打必须留痕 |
| 存储 | 视频、照片、附件统一文件服务或对象存储 |
| 备份 | 数据库每日备份，附件按存储策略备份 |
| 兼容 | PC 支持主流 Chromium 浏览器；移动端优先 Android Chrome |

## 7. 一期验收目标

一期必须使用真实业务样例完成端到端验收：

1. 创建客户订单。
2. 扫描快递单号生成来料记录。
3. 拆包称重并生成母单。
4. 打印母单标签。
5. 生成客户所有待加工库存。
6. 拆分两个子工单。
7. 打印子工单标签。
8. PWA 扫码进入报工。
9. 完成第一道工序并记录称重交接。
10. 第二道工序质检不合格并生成返工。
11. 返工完成后复检通过。
12. 记录一次超标损耗并生成审批。
13. 成品入库。
14. 创建部分出库单并冻结库存。
15. 打包称重并关联视频。
16. 确认发货并扣减库存。
17. 通过母单和快递单号查看完整追溯。
18. 导出产量、损耗、库存、工资试算报表。

## 8. 待业务确认事项

- 试点产品、试点工序、试点员工和试点车间范围。
- 母单拆分是否必须同时按数量和重量完全拆平。
- 各物料和工序的标准损耗率来源。
- 损耗责任按个人、班组还是管理人员归因。
- 哪些工序必须质检。
- 返工次数上限和超限审批人。
- 视频保存周期和存储位置。
- 标签尺寸、打印机类型和标签内容。
- 是否需要导入历史库存。
- 是否有现成 NVR、摄像头、扫码枪、打印机、电子秤型号。
