# 收料建单与材质保存标识改造方案

日期：2026-10-25。本文记录本轮已确认的实施顺序和验收约定，不代表已经部署或现场验收。总进度、提交和验证事实只维护在[项目核心](./00_项目核心.md)。

## 1. 本轮目标

桌面与手机继续共用收料业务：选择客户和材质，填写来料、要求及交期，随时拍照，确认建单并入库，照片自动关联，然后在本页安排整单生产或拆单。客户、材质及公共模板维护按需进入。特殊材质的保存要求从档案带到业务来源和标签，以固定圆章表达。

实施复用现有领域、工作单元、权限、单号和标签身份。保留工作区已有样式及业务改动，不将其混入本轮提交。以下各增量串行实施、定向验证、独立提交。

## 2. 已确认的设计

- 建单前可拍照、录像或从相册选文件，先留在本次草稿；拍照不隐式建单、入库。
- 主按钮为“确认建单并入库”。取得正式母单和对应业务操作编号后，自动上传并关联本草稿照片；新增照片按同样规则办理。
- 业务、附件、打印分别显示结果。业务成功后附件失败只重试附件；已上传而关联失败时只补关联。
- 客户、材质新增表单不常驻。选择框菜单及搜索无匹配时提供有权限的快捷新增，弹窗保存后选回当前字段。完整编辑、停用、模板及快捷词维护集中在基础资料。
- 收料页保留选择加工要求模板、常用要求和本单补充说明；自定义本单步骤按需展开，不将本单文字自动保存为公共资料。
- 保存后在本页提供“整单生产”“拆成子单”“稍后安排”。母单收货标签可先打印，生产流转标签根据正式安排生成；不因打印母单标签自动确认不拆。
- 保存标识使用固定字典：冷＝冷藏、冻＝冷冻、真＝真空、光＝避光、潮＝防潮。每个字独立画圆，黑白粗线和居中汉字，不依赖特殊圈字字体。
- 星月的“冷、真”按本次用户提供的规则配置，不推断其他材质的实际要求、温度或时限。无配置表示未设置要求，不默认为常温。

## 3. 确认方案时的代码基线与实施前核对

| 草稿 | 收起面板保留当前实例，文件和迟到的异步处理按草稿隔离；刷新恢复仍属 R6 | `frontend/src/features/orders/OrderActionHost.vue`、`frontend/src/features/evidence/EvidenceCapture.vue` |

## 4. 串行实施顺序

### R1：修复收料照片与正式单据的衔接

先解决现有断点，保留当前表单布局，便于单独确认修复效果。

1. 复现新母单建单前上传、保存后上传、重新打开已有母单补拍三条路径，核对实际提示及请求。
2. 草稿阶段只显示“已选若干文件，建单后自动上传”，不提供无法执行的上传关联按钮。
3. 收料场景显式启用自动上传；共享证据组件的生产、质检、发货默认行为保持原契约。
4. 保存成功后固定草稿与母单身份，使用服务端实际操作编号关联；已有母单补拍先读取真实收货来源，不根据单号猜操作类型或伪造编号。
5. 每个文件限制一次并行处理。照片时间处理开始时固定草稿归属，切单后迟到结果不能进入新草稿。保留附件编号，关联重试不重复上传。
6. 同页显示业务成功和附件进度；失败后保留文件及原请求，下一笔收料不能接管上一笔文件。

验收：建单前选文件不调用业务和上传接口；建单后自动关联；取消相机不建单；上传、绑定失败可各自重试；建单超时原请求恢复；切单及异步照片处理不串单；已有单可补拍；共享证据场景相关回归通过。

### R2：收起低频维护，简化填写

1. 移除常驻客户和材质新增组，改成按需快捷弹窗。可在有相近搜索结果时主动新增，不局限于无匹配。
2. 保存后将客户选回客户字段，将材质选回发起新增的准确明细行；取消弹窗不改变原选择，不丢其他字段及照片。
3. 公共快捷词删除、新增和模板维护移到现有基础资料；本单步骤按需展开，保留最终要求的查看和编辑。
4. 按原权限控制维护；新客户范围沿用原服务规则。选择框复用改动不能影响其他消费者。
5. 两段填写保持不变，增加客户及明细摘要、逐行错误提示、明确按钮文案；相同单位及现有重量约束提前提示。

验收：普通录入无常驻维护区；有无权限、新增取消、同名处理、多行正确回填；要求模板使用与已手改文字保护；手机与桌面定向检查。

### R3：保存条件主数据与来源快照

此增量先完成数据，不先画圆章，避免标签读实时材质档案而改写历史含义。

1. 材质增加标准保存条件和完整补充说明，提供维护及只读展示。固定字典、顺序和重复值校验；冷藏与冷冻同时选择时明确拒绝或提示修正。
2. 接口、内存和 JDBC 同步支持；采用实际下一可用迁移版本追加脚本，保留旧构造器及旧请求兼容。旧客户端未传新字段时不能意外清空已有要求，明确并测试更新语义。
3. 新收货逐行保存条件快照，寄存按来源明细／批次保存；从备料建单、来源分配及子单继承同一来源快照，不读取最新档案覆盖。
4. 老记录没有快照时明确“未记录”，不得伪称当时无特殊要求；不批量回填为历史事实。材质后续修改需要有修改记录，并能定向列出相关在库／在制记录供核对。
5. 页面在材质旁显示短提示，展开查看完整说明；普通收料无需重复填写。暂不增加自由覆盖要求、实际冷柜登记或新的审批流程。

验收：档案保存读取、原数据兼容、旧请求不清空、内存与 JDBC 持久化；多行不同条件、备料来源及子单继承；修改档案不改变既有快照。涉及同事务写入时覆盖失败回滚。

### R4：圆章标签及各打印路径

1. 新增独立保存标识载荷，以已保存业务快照为来源，由服务端组装；打印任务冻结完整内容及标识，不由前端任意填写。
2. 为 40×30 mm 标签安排固定提示区，各圆章独立绘制。优先保证单号、母子关系、二维码及保存标识清晰，次要内容可按版式压缩。
3. 同步后端标签组装、模板支持、网页预览／打印、任务快照、Windows 接收程序及仍在使用的 Java 绘制路径。自定义模板也须保留存在特殊要求时的提示区。
4. 多材质母单须说明圆章适用哪一行；空间不足时明确要求分明细标签或调整版式，不打印为无归属的条件并集，不静默遗漏。子单只显示自身来源要求。
5. 同版补打沿用原内容；采用更新后的保存要求须走明确的新版本／换贴，保留旧任务。核对当前补打实现，不能因重新查询档案而变更旧版内容。
6. 寄存批次如没有现成标签身份，单独补其合法身份及权限后才开放打印，不用虚构母单号代替批次。

验收：无条件、冷＋真、多条件、子单、多材质、旧载荷及自定义模板；默认紧凑模式不丢章，标识不遮二维码；网页和两种程序绘制对照；补打快照不变。实机出纸和扫码单独记录结果。

### R5：保存后生产安排与拆单减负

1. 保存结果明确区分“已入库”“待安排”“附件处理中／待补”，按权限在本页继续整单、拆单或稍后安排。
2. 明确确认后才调用不拆或拆单命令。多材质不得不拆，现有已确认不拆后的限制仍生效；收货标签不改变生产决定。
3. 拆单以来源分配为唯一录入基础，子单数量重量自动计算；提供“按明细生成草稿”和“填入剩余”。所有建议经人工核对后提交。
4. 不自动合并同材质不同来源行，不按数量比例猜测实称重量；数量、重量分别守恒，允许按现有规则保留母单未分配余量。
5. 正式工序与要求文字分开处理，沿用有效工序能力及权限，不把文字步骤自动变为岗位或计费项目。

验收：有无生产安排权限、稍后继续、整单和多材质拒绝、部分分配、来源剩余、精确小数、失败回滚、原请求重试和并发超领；标签失败不误报拆单失败或再次拆单。

### R6：寄存衔接、连续收料与草稿恢复

1. 选择先寄存时衔接已录客户、明细和真实来源，同时维持加工与寄存各自草稿和照片身份；用途切换不得隐式提交或重复入库。
2. 已寄存再加工只走原批次领用建单，校验客户、物料、单位、数量重量及保存条件来源，复验 JDBC 同事务回滚与并发不透支。
3. 提供“同运单继续”“同客户再收”“全新收料”，明确各自继承字段；新一笔使用新请求，数量、重量、照片重新录入，要求及交期仅显式复用。
4. 收起恢复继续利用现有实例；刷新恢复另存表单、实际文件和不可变提交快照，按账号隔离。发生网络结果不明时先恢复原请求，不因编辑产生重复收货。
5. 本机草稿文件的清理、容量失败及退出处理明确展示；如果首期只能做到离开提醒，应如实标记，不能称为已支持刷新恢复。
6. 加工意图下信息不全的新“待核收货”状态需先补服务契约和保存位置；正式单约束未扩展前，不放开空重量入库，也不强制改为寄存用途。

验收：寄存待核到确认、备料转加工总库存守恒、两用途草稿隔离、同运单多母单、刷新恢复照片、账号隔离、超时恢复及两个并发领用。

## 5. 验证与交付方式

- 每个增量先执行受影响组件、服务及直接调用链的最小充分验证，通过即停止扩大；不默认全量测试、生产构建或交付打包。
- R3 的迁移和 R4 的打印载荷属于兼容性改动，按实际影响补相关类型检查、仓储／升级及绘制检查。若制作打印程序或交付包，执行对应实际产物验证，不将模拟绘制当成实机出纸。
- 最后用一组虚构现场样单贯通：星月冷＋真、新建前拍照、附件失败重试、稍后安排再拆单、寄存领用建单、旧标签补打；桌面和手机分别检查。
- 每次提交仅纳入本增量，保留原工作区改动。实际完成、验证和阻断同步项目核心；接口或规则实际变化后再更新对应专题。
- 部署单独办理，执行本地方案不表示已经发布或完成现场验收。

## 6. 第一版边界

第一批可用成果为 R1＋R2：照片衔接修复及收料页面简化。第二批为 R3＋R4：保存要求和圆章从数据到打印贯通。第三批为 R5＋R6：生产安排、拆单及寄存连续作业。

本轮不顺带扩展跨材质子单、混合单位加工母单、多原料合成、传感器温控、物理库位系统或全面库存重构；如现场需要批次例外、温度时限参数、历史批量换贴，另明确具体规则后追加小增量。
