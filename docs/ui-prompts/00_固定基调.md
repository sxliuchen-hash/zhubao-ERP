# 固定基调与共同执行规则

本文件由用户要求预先确定。执行当前任务，不重新进行开放式产品规划。总体背景必要时查 `docs/26_ERP整体UI与多端设计规划.md` 对应章节，不要求每轮全文阅读。

## 设计决定

- 定位：专业、清晰、克制的珠宝加工 ERP，办公管理与现场作业分别组织。
- 颜色：导航 `#17263C`；主操作 `#315FD1`；工作区 `#F3F5F9`；内容 `#FFFFFF`；边线 `#E2E7EF`；主字 `#17263C`；次字 `#617087`；品牌暖金 `#AE8A52`。
- 全站语义令牌管理颜色。暖金不用于大面积表格、主按钮和金额背景；禁止各模块自行定义另一套主题。第一版只做浅色工作区。
- 桌面正文 14px、标题 20–24px；手机正文与输入 16px。金额等宽数字、千分位、右对齐；明细两位小数并带单位。
- 间距用 4／8／12／16／24／32px；按钮与输入圆角 6px，内容区 10px。桌面标准行高 44px，必要时紧凑为 36px；手机点击目标至少 44px。
- 状态配文字：成功绿、处理中蓝、待办／警告橙、失败／逾期红、草稿灰。一套线性图标，重要操作有中文标签。
- 桌面：业务导航＋上下文页头＋筛选＋列表／详情。经营看板允许指标卡；日常单据页不堆装饰卡片、重复标题或说明大段。
- 手机：任务优先、单据卡片、单独详情和分步表单。核心动作不靠横滑桌面宽表格。底部入口为现有「工作台、现场作业、审批、更多」，按权限裁剪。
- 320、375、390、768、1024、1440px 均须正常；外层不横向溢出。保留键盘焦点、可读对比度、减少动态效果设置，重要内容不依赖悬停。
- 黑白标签与毫米纸张独立于应用皮肤，不把品牌色带进打印。

## 开发约束

1. 先读 AGENTS.md、实时 `git status` 和当前任务文件。检查前置任务的实际代码与提交，不信未经验证的“已完成”文字。
2. 只读当前任务相关文件。涉及重度测试服务时按 AGENTS.md 先调研调用链与影响面；其他简单任务不无目的扫描或泛滥拆代理。
3. 沿用 Vue 3、TypeScript、Vite、自有 CSS 和现有 API 客户端。第一版不新增 UI 库、图表库、路由库或跨端应用框架。
4. 优先复用已有 `AppShell`、`StatusBadge`、`NavIcon` 与业务类型。有重复需求再抽实际使用的基础组件，禁止先造一批无调用组件。
5. 不改菜单编码、登录机制、业务状态机、计价公式、库存命令、扫码编码、打印协议。当前任务明确要求的后端授权及聚合例外；保留 DDD、内存／JDBC、构造器兼容和迁移规则。
6. 不新增硬编码客户、单据、金额、日期作为运行数据。样例只在测试或明确隔离的设计资料中使用。缺接口显示尚不可用，不能造假数据补齐。
7. 无数据、失败、无权限、缺项、加载中分别处理；保存失败保留输入。没有已实现动作就不做可点击假入口。
8. 不覆盖现有未提交修改，不删除依赖、锁文件或已发布迁移，不自动部署、推送或开始下一段。提交只暂存本段变更。
9. 未定义的账务语义先给代码证据和最小待确认问题；不能为了画满仪表盘自行发明计价、分摊、余额或授权规则。

## 财务不可改变的口径

- `revenue` 为入账加工费净额，不是实收；`result` 为减去已记录成本后的经营结余，不是净利润。展示 `gaps`，缺项时标暂估。
- 客户账单 `receivedAmount` 为所选账单累计核销额，不是本月实收；应付 `paidAmount` 也不是本月实际付款。
- 选择月份只影响期间收入、成本和趋势；第一版余额与排行均为「截至当前」，返回实际 `asOf`。不实现或暗示历史月末回放。
- 客户来料数量／克重不是企业自有资产金额。公司折旧及未分配成本不自动摊给客户；客户结余不承诺相加等于公司结余。
- 后端权威计算金额；不对分页表或逐客户请求结果前端相加来冒充全量指标。只读查询绝不触发生成账单、工资、折旧或核销。
- 所有汇总、趋势、排行和明细须有服务端读取授权及相同客户范围。隐藏按钮、隐藏金额、传入 customerId 都不是授权。
- 第一版不做账龄、预算、银行余额、净利润、完整现金流、历史余额回放或新增成本分摊模型。

## 完成与停止

补充有意义的行为测试，不能以 CSS 常量断言替代浏览器检查。按 AGENTS.md 完成后端全量测试、前端全量测试与构建、包结构门禁；使用环境替代命令或无镜像门禁时如实写明。基线失败先定位，不扩大范围修无关问题，不把失败写成通过。

同步 README、docs/14_开发进度跟踪.md、docs/23_客户交付版本记录.md，以及 docs/27_UI开发执行提示词.md 的当前任务状态。测试通过后按项目规则独立提交；遇到环境或身份阻断则保留成果并如实说明，不能捏造提交号。

结束报告固定包含：任务编号；用户能看到的变化；改动文件；电脑／手机截图路径；实际测试命令及结果；本段提交号；未完成与未验证项；下一任务编号。完成当前段后停止，等待用户启动下一段。
