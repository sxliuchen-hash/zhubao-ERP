# UI-08：手机收货、报工与质检

前置：UI-07 已完成。读取共同基调、手机作业参考图及 `docs/24_手机现场采集方案.md`、`docs/25_现场作业收口计划.md` 对应流程。

## 起点与范围

从 `MobileOpsWorkspace.vue`、现有扫码模块、收货／报工／质检 API 和测试开始。当前工作区可能已有 HTTPS 与手机扫码改动，先查差异并保留。只重排交互和表现，不重写扫码、视频、库存或工序状态机。

## 实施

1. 手机收货：扫快递单／手工输入 → 客户、要求与期限 → 建母单 → 拆包视频上传状态 → 标签入口。草稿和已保存状态明确。
2. 手机报工：扫母单／子单贴纸 → 显示当前单身份和账号绑定工序 → 核对本岗位要求 → 输入实际必填数量／重量等 → 确认提交 → 服务端成功结果。
3. 手机质检：扫单 → 逐条要求 → 判定与问题 → 现有证据上传 → 提交结果，质检员仍取当前登录人。
4. 不给操作工收款入口，不提前显示其他岗位可提交动作。核对勾选不等于服务端报工成功，不新增未经业务定义的强制检查规则。
5. 大触控目标、单列表单、底部主动作、安全区和软键盘正常。拍摄拒绝、弱光识别失败、网络中断、上传失败和登录过期可恢复。
6. 保留手工输入与现有照片识别回退；上传成功和业务保存成功分别反馈。离线自动补账与自建任务队列不在本段范围。

## 完成条件

有扫码输入回退、岗位限制、必填校验、保存失败保留输入、上传重试与重复提交的测试。浏览器检查 320／390px；真机的摄像头、弱光、切后台、键盘、安全区需实际验证。没有真机时如实列为「未验证」，不能写全部验收通过。
