# UI-10：整体验收与回归

前置：UI-01 至 UI-08、UI-09 所有目标模块均已实际完成。

本段验证最终结果和修复本轮改版引入的缺陷，不另选风格、增加新功能或启动 APP 工程。

## 检查

1. 按共同基调检查全站标题、按钮、筛选、金额、图标、状态、密度与响应式，找出还在使用旧皮肤的页面。
2. 核对授权菜单全部可到达；追溯、登录改密、退出、附件、打印、手机作业与原业务命令不回退。
3. 财务四指标、趋势、排行与明细在同一稳定样例可手工核对；月份与当前余额时点分清；缺项和权限真实，查询不写账。
4. 用有权限、无财务权限、单客户范围和公司范围账号检查服务端数据边界。
5. 浏览器覆盖 320／375／390／768／1024／1440px、长字段、大金额、负结余、空数据、部分失败、慢请求和键盘焦点。
6. 真机验证摄像头、上传、切后台、弱网、键盘、安全区与重复提交。无法执行的项单列，不拿模拟视口当真机通过。
7. 执行 AGENTS.md 全部基线。验证当前代码对应的包结构，记录包路径与镜像是否存在；旧布局包通过只能作为旧包检查，不能证明本轮交付。
