# UI-01：统一主题与基础样式

前置：读取共同基调。仅执行本段，完成后停止。

## 起点与范围

先读 `frontend/src/styles.css`、`frontend/src/components/StatusBadge.vue`、`frontend/src/components/NavIcon.vue`，再读已有样式引用处以确认影响范围。

允许修改全站主题令牌、通用文字／按钮／输入／表格／状态／焦点样式。必要时调整现有基础组件；不改业务页面结构、App 导航、API、后端或依赖。

## 实施

1. 使用共同基调的配色、字号、间距与圆角，统一现有主题变量。保证仍引用旧变量的页面可正常显示；迁移后再移除无人使用的变量。
2. 统一主按钮、次按钮、危险操作、禁用和保存中状态；不能通过大串 `!important` 覆盖解决问题。
3. 金额与表格数值统一对齐；保留长单号、负数、极大值的可读性。
4. 保留已有状态含义与图标名称，改善视觉一致性；不新增另一套状态组件。
5. 不提前创建后续页面或大量无调用基础组件，不把所有旧类一次重命名。

## 完成条件

登录、首页、来料、财务现有页面均能显示；按钮和输入可操作，状态不混淆。检查 390 与 1440px，另在 320px 检查外层溢出。打印预览仍黑白且不受全站皮肤污染。

按共同规则验证、同步文档、独立提交。下一段是 UI-02，不能自动执行。
