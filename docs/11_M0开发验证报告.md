# 来料加工进销存与生产管理系统 M0 开发验证报告

**文档版本**：V1.0  
**阶段**：M0 关键风险验证  
**实现范围**：工程基础、测试套件、前后端分离、核心领域原型

---

## 1. M0 目标

M0 不实现完整业务闭环，目标是验证长期开发基础是否成立：

- 前后端分离工程能运行。
- 后端具备可测试的领域服务基础。
- 前端具备 PWA 和组件化基础。
- 库存台账模型能用转移命令表达。
- 扫码解析规则能前后端一致实现。
- 视频截取任务能表达异步和人工兜底。
- 测试套件能覆盖核心风险。
