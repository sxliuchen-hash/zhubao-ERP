# 客户确认单（试点上线前）

**文档版本**：V1.0
**日期**：2026-07-09
**用途**：试点上线前需要客户/业务方确认的信息汇总。请逐项填写"确认结论"，涉及数据的附在最后或另发文件。
**填写方式**：可直接在本表"确认结论"列填写，或口头告知我们由我们代填后请您核对。

---

## 一、怎么用这份表

- 这份表不是让您懂技术，而是把"系统按什么规则算、用什么数据"这些**只有您和车间/仓库最清楚**的事定下来。
- 规则没定之前，系统不能拿"我们猜的规则"给您正式用，否则算错账、扣错工资，返工更麻烦。
- 带 ⭐ 的是**最关键、必须先定**的，其它可以边试点边定。

---

## 二、⭐ 必须先确认的（决定能不能开始试点）

| 编号 | 我们要问的事 | 为什么要问 | 我们的建议默认 | 您的确认结论 |
|---|---|---|---|---|
| Q1 ⭐ | 损耗怎么算？按**重量**、**件数**还是**金额**？ | 决定损耗、审批、工资试算怎么算 | 贵重料按重量、普通件按数量，金额只做参考 | |
| Q2 ⭐ | 每道工序的**标准损耗率**是多少？（比如抛光允许损耗 %） | 超过这个比例才报警/走审批 | 由您给出各工序数值 | |
| Q3 ⭐ | 什么算"**合理损耗/合理转移**"，什么算"超标"？ | 避免把正常损耗算成责任损耗 | 返修、留样、客户确认的报废单独记，不算超标 | |
| Q4 ⭐ | 损耗责任算**个人**、**班组**还是**只记录不追责**？ | 影响报表和是否扣工资 | 一期只记录、只试算，不真扣工资 | |
| Q5 ⭐ | 质检结果有哪几种？（合格 / 返工 / 报废 / 让步通过 / 待复检 …） | 决定质检和返工流程 | 合格、返工、报废、让步通过、待复检 | |
| Q6 ⭐ | 返工有没有**次数上限**？超了要不要审批？ | 控制反复返工 | 记录次数，超限提示审批，不自动禁止 | |
| Q7 ⭐ | 客户退货后怎么处理？（重新入库 / 返工 / 报废 / 冻结） | 决定退货流程 | 复核后分流：入库、返工、报废、冻结 | |
| Q8 ⭐ | 出货的"**交货类目**"有哪几种？（成品 / 返修件 / 补发件 / 样品 …） | 出货单要选类目 | 成品、返修件、补发件、样品、退补件 | |

## 三、⭐ 必须提供的"真实数据"（决定能不能用真数据跑通）

请提供以下**脱敏**数据（真实名字可换成简称或编号，价格可用大概区间）。可以是 Excel、拍照或手写，我们来整理。

| 编号 | 要什么 | 最少几条 | 每条包含 |
|---|---|---|---|
| D1 ⭐ | 客户名单 | 5 个 | 客户简称、联系人、默认发货方式 |
| D2 ⭐ | 物料清单 | 20 个 | 名称、规格、按什么计量（克/颗/件）、是否贵重 |
| D3 ⭐ | 工序清单 | 10 个 | 工序名、是否用机器、是否计件、是否要质检、是否要称重 |
| D4 ⭐ | 工序模板（加工流程） | 3 套 | 每类产品的工序先后顺序 |
| D5 | 员工/班组名单 | 10 个 | 姓名（可用编号）、班组、能做哪些工序 |
| D6 | 仓库清单 | 6 个 | 仓库名、用途 |
| D7 ⭐ | 几张真实单据样例（可拍照） | 各 3–5 张 | 来料单、报工/抛光日报、雕刻机统计、出货单、退货单 |
