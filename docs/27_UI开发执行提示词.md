## 启动与验收

当前从 UI-06 开始。切换模型后只读取共同规范、当前任务及指定代码；先核对前置实现和实时工作区，不自动执行后续任务。

```text
请在 F:\APPkaifa\zhubao-ERP 中执行 UI-06。
读取 AGENTS.md、docs/ui-prompts/00_固定基调.md、docs/ui-prompts/UI-06_当前余额与下钻.md。
先检查 git status，保护已有未提交改动，并核对 UI-04、UI-05 的实际代码、提交和接口契约。
仅完成当前余额、客户排行与明细下钻，不提前制作仪表盘，不继续 UI-07。
按项目规则完成开发、验证和文档同步，更新 docs/27 的任务状态，独立提交并报告结果后停止。
```

以后将任务编号与文件路径替换为状态表中的当前任务。UI-09 同时指定本轮模块；UI-11 需要用户另外启动。

验收时对照任务条件报告「已满足／未满足／未验证」，提供实际差异、测试、电脑／手机截图和提交；环境替代命令、真机缺项及包门禁限制如实记录。发现本段缺陷先修复，不扩展到其他任务。
