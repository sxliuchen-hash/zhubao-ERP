## 启动与验收

当前 UI-09 进行中，审批之前的模块已迁移。切换模型后只读取共同规范、当前任务及指定代码；先核对前置实现和实时工作区，不自动执行后续任务。UI-09 必须由用户指定本轮模块；没有指定时从财务登记表单开始，并且只做这一个模块。

```text
请在 F:\APPkaifa\zhubao-ERP 中执行 UI-09，本轮模块为财务登记表单。
读取 AGENTS.md、docs/ui-prompts/00_固定基调.md、docs/ui-prompts/UI-09_单模块迁移.md。
先检查 git status，保护已有未提交改动，并核对审批模块的实际代码和提交。
仅迁移这一个模块，不继续下一个模块，也不进入 UI-10。
按项目规则完成开发、验证和文档同步，更新 docs/27 的任务状态，独立提交并报告结果后停止。
```

以后将任务编号与文件路径替换为状态表中的当前任务。UI-09 同时指定本轮模块；UI-11 需要用户另外启动。

验收时对照任务条件报告「已满足／未满足／未验证」，提供实际差异、测试、电脑／手机截图和提交；环境替代命令、真机缺项及包门禁限制如实记录。发现本段缺陷先修复，不扩展到其他任务。
