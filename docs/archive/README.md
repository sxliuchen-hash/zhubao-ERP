# 历史归档

本文只提供来源索引。当前范围、架构、状态和下一步以 [项目核心](../00_项目核心.md) 为准；现行专题见 [文档入口](../README.md)。

归档反映编写时的需求、决定、执行指令或验证结果，停止日常维护。不自动执行旧提示词，不将历史测试通过写成当前环境验收，不将远期方案写成已交付功能。新的业务决定更新核心或对应专题；首次真实交付再建立实际客户版本记录。
