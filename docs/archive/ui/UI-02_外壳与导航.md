## 起点与范围

允许改外壳、导航展示与相关测试。不改后台权限、现有 TabKey 和菜单编码、登录行为、业务页面命令；本段不引入 vue-router。

## 实施

1. 电脑采用深蓝灰侧栏、品牌区、分组菜单、当前选中态及收起按钮；顶部保留日期、追溯输入、账号与退出。
2. 按六个业务分组归类现有入口：工作台、来料与订单、生产与质量、库存与交付、财务经营、协同与系统。展示层分组不能产生新权限。
3. 页面标题与当前位置清晰，避免模块内部重复一组大标题。保留现有追溯和跳转注入契约。
4. 手机使用紧凑页头与「工作台、现场作业、审批、更多」导航，映射现有授权入口；没有权限的项不显示。「更多」展开当前用户有权访问的其他菜单，所有现有授权模块仍可到达。
5. 不使用消息、扫码或我的空页面充数。现场作业可到现有手机页；扫码只在具备真实功能的业务页面触发。
6. 底部安全区、软键盘与内容留白正常；桌面与手机的同一次操作不产生两份业务状态。
