## 起点与范围

先读 `frontend/src/features/m1/InboundWorkspace.vue`、相关业务 API 与测试、现有 `StatusBadge`。仅迁移来料页面及实际被调用的共享组件，不改收货、拆单、标签与库存命令。

## 实施

1. 统一为「页头与主动作 → 常用筛选 → 单据列表 → 选中单据详情」。高级筛选可收起，新增表单不再长期压在长列表下方。
2. 电脑列表保留单号、客户、加工要求／期限、数量／重量和状态；宽屏显示详情，窄屏改独立详情或抽屉。财务金额不从来料页推算。
3. 手机用卡片列表，首行单号与状态，接着客户、期限与关键数量。点进详情后处理，不依赖横滑大表格完成核心动作。
4. 保留真实接口加载、全局追溯、客户过滤、已有视频回看、母单不拆／拆分、黑白标签打印入口与错误处理。
5. 根据实际重复需要提取页头、筛选、移动列表、详情分区组件；接口与业务状态留在原业务层，不能为抽组件重写命令。

## 完成条件

测试筛选、选中、详情返回、无数据、加载失败、视频不可用、拆单和打印入口；手机返回保留筛选和已选状态。对照 390 和 1440px 截图，另检查 320px 长单号与大数量。
