# 样张设计规范（客户展示样张 + 后续开发模板）

> 归档说明：本目录保存历史客户展示样张和当时的视觉规范；当前界面设计以[现行文档索引](../../../README.md)为准，不再向本目录追加开发模板。

**用途**：本目录 `docs/archive/customer/samples/` 下的 HTML 样张既用于客户展示，也作为后续前端页面开发的视觉/结构模板。新增样张请遵循本规范，保持风格统一、可复用。

---

## 一、统一配色

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色（深底/标题栏） | `#1f2733` | 页头、标签头 |
| 背景 | `#eef1f5` | 页面底色 |
| 卡片白 | `#ffffff` | 内容卡片 |
| 强调蓝 | `#3b6fb0` | 链接、主按钮、订单类 |
| 成功绿 | `#2f9e57` | 已完成、合格、子工单 |
| 警告黄 | `#d99a2b` / `#f4b740` | 加工中、待处理、周转盒 |
| 危险红 | `#c85a6a` | 超标、异常、返工 |
| 次要文字 | `#6b7684` | 说明、hint |

状态标签（tag）配色：绿 `#e4f5ea/#1f8b4c`、黄 `#fdf0d5/#a86a12`、红 `#fde8ea/#c0334a`、蓝 `#e8f0fb/#3b6fb0`。

---

## 二、统一结构

- 字体：`"微软雅黑", "Microsoft YaHei", sans-serif`
- 页首：`h1` 标题 + `.note` 说明（浅灰、居中、13px）
- 内容：`.wrap`（max-width 860~980px、居中）内放 `.card`（圆角 12px、阴影）
- 卡片：深色 `.card-head` + 白色 `.card-body`
- 打印：`@media print` 隐藏 `.note` 等说明性元素，去背景色

---

## 三、命名与放置

- 文件名用中文，见名知意，以"样张"结尾：`XX样张.html`
- 开发产出物放 `output/样张/`（不进 git），重要样张同步一份到 `docs/archive/customer/samples/`（进 git 存档）
- 所有文案中文；二维码内容沿用系统扫码格式 `JG|类型|编码`

## 五、作为开发模板的用法

后续做真实前端页面时：
- 追溯页参考 `全链路追溯展示.html` 的时间线 + 台账 + 证据链结构
- 首页看板参考 `老板首页看板样张.html` 的 KPI 卡 + 单据池 + 异常区
- 标签打印功能参考标签样张的"固定信息 + 二维码"布局，进度信息不进标签
- 移动端参考 `手机扫码报工流程样张.html` 的手机框 + 3 步交互

这些样张的配色和结构应逐步沉淀为前端公共样式（`frontend/src/styles.css`）和组件。
