## 1. 产品定位

本系统面向客户来料加工业务，完整产品目标覆盖来料收货、拆包称重、母单建档、子工单拆分、工序报工、质检返工、库存台账、成品出库、手机证据、全链路追溯和基础经营核算。以下模块、状态机和验收目标包含待建设内容；是否已落地以开发进度、实际代码和接口契约为准，不能把目标范围当作全部已实现。

系统不是普通进销存，也不是完整财务 ERP。它的核心是以“客户来料批次”为中心，建立可追溯、可核对、可解释的加工管理闭环。

### 1.1 业务痛点

- 客户来料、半成品、成品、返工品、报废品状态不清，账实难核对。
- 贵重物料损耗缺少按工序、员工、称重交接和证据链的解释。
- 纸质工单流转慢，生产进度无法实时掌握。
- 质检不合格、返工、报废缺少统一流程和责任归因。
- 拆包和打包视频虽然存在，但难以和业务单据自动关联。
- 计件工资依赖人工统计，容易漏算、错算、争议大。

### 1.2 建设目标

| 目标 | 说明 |
|---|---|
| 全链路追溯 | 母单、子工单、工序、质检、返工、损耗、库存、出库、视频可串联查询 |
| 库存可核对 | 所有库存变化均由业务单据驱动，生成库存台账 |
| 损耗可解释 | 损耗按工序投入重量计算，并关联称重交接、责任归因和审批 |
| 作业可扫码 | 现场通过 PWA 移动网页或扫码枪完成报工、质检和查询 |
| 经营可核对 | 客户协议计价、收款、工资试算与确认、基础应付、消耗品和资产折旧形成经营核算；不自动发薪 |
| 证据可留存 | 拆包、打包、异常处理支持视频或附件证据 |
| 权限可隔离 | 不同岗位按角色和数据范围访问系统 |

## 2. 分期范围

### 2.1 一期范围：核心闭环可运行

一期目标是替代手工台账，跑通真实业务链路。

一期必须包含：

- 基础档案：客户、物料、工序、工序模板、员工、仓库、计件单价、损耗率。
- 客户订单：订单建档、订单状态、关联母单和出库。
- 来料入库：扫码收货、签收登记、拆包登记、称重、母单生成、客户所有库存入账。
- 标签打印：母单标签、子工单标签、出库标签。
- 生产工单：母单拆分子工单、工序实例生成、分配、扫码报工、工序日记录。
- 雕刻设备统计：按日期、客户、品类、机器编号、雕刻数量和操机签字统计产能。
- 称重交接：关键工序记录投入重量、产出重量、交接人和证据。
- 质检返工：质检合格、不合格、返工、报废、让步通过、复检。
- 损耗管理：按工序计算损耗，超标损耗触发轻量审批。
- 库存管理：库存台账、库存余额、库存冻结、库存调整。
- 出库管理：成品选择、冻结库存、交货登记、打包称重、发货扣库存。
- 全链路追溯：按母单、子工单、快递单号、客户查询时间线。
- 基础经营核算：客户按克、按件或按工序协议计价，形成加工费账单与收款核销；工资按单价快照试算、确认并形成基础应付，记录消耗品采购与领用、固定资产折旧、外协和付款。
- PWA 移动网页：扫码、报工、质检、库存查询。
- 现场证据：手机上传拆包、称重、缺陷和成品照片或短视频；录像机按时间截取仅保留为后续备选，不进入当前作业路径。
- 轻量审批：来料异常、损耗超标、返工超次数、报废、库存调整。

### 2.2 一期明确不做

以下事项不进入一期主验收：

- 银行代发、正式工资扣发和完整薪酬结算。已有工资确认及确认后限制修改属于基础经营核算，不应再整体列为排除项。
- 会计凭证、总账、完整成本会计和银行账户核算。客户加工费应收、收款及公司基础应付已经纳入经营核算范围。
- 完整工作流引擎和复杂审批流编排。
- 原生 Android App。
- 电子秤自动采集强集成。
- 完整库存盘点审核。
- 复杂 BI 大屏和超出现有账务口径的分析；现有基础经营报表和已规划的只读经营看板继续推进。
- 客户门户、小程序、外部客户协同。
- 快递、短信、财务软件、人脸门禁等外部系统正式集成。

### 2.3 二期范围：效率和管理增强

- 电子秤自动采集和设备绑定。
- 完整盘点、盘亏盘盈审批。
- 在已有工资试算、确认和基础应付之上扩展正式薪酬结算、调整、扣减审批及支付集成，具体范围另行确认。
- 更完整的返工、报废、退货流程。
- 复杂审批流和流程引擎。
- Android 原生或专用 PDA 支持。
- 高级报表、异常预警和经营看板。

### 2.4 三期范围：外部协同和智能化

- 客户查询门户。
- 快递、短信、财务系统集成。
- AI 视频辅助识别、损耗异常预警。
- 多工厂、多组织、多租户。

## 3. 角色与权限

| 角色 | 核心诉求 | 一期功能 |
|---|---|---|
| 总经理/负责人 | 查看关键数据，审批异常 | 首页看板、审批、追溯、报表 |
| 业务员/客服 | 录入客户订单，跟进交付 | 客户订单、进度查询、出库状态 |
| 收货员 | 收货、拆包、称重、标签 | 来料入库、母单标签、拆包视频 |
| 车间组长 | 拆分工单、安排生产、处理异常 | 工单拆分、分配、返工处理 |
| 操作工 | 扫码领取任务，完成报工 | PWA 扫码、报工、我的任务 |
| 质检员 | 判断质量，发起返工/报废 | 待质检、质检操作、复检 |
| 库管员 | 管理库存和出库 | 库存查询、出库、打包、发货 |
| 财务/统计 | 核对加工费、收付和经营成本 | 客户账单、收款、工资试算与确认、基础应付、消耗品、资产折旧和经营报表 |
| 系统管理员 | 用户、权限、配置 | 权限、参数、字典、日志 |

权限模型采用 RBAC + 数据范围：

- 功能权限控制页面、按钮、导入导出和敏感操作。
- 数据范围支持本人、本班组、本部门、全部、自定义客户范围。
- 敏感操作必须写入操作日志。

## 4. 核心业务闭环

一期主链路：

1. 创建客户和客户订单。
2. 收到客户来料，扫描快递单号。
3. 拆包、称重、拍照或记录视频时间。
4. 确认来料信息，生成母单和母单标签。
5. 生成客户所有的待加工库存。
6. 车间组长将母单拆分为多个子工单。
7. 系统按工序模板生成工序实例。
8. 打印子工单标签并分配给员工或工位。
9. 操作工扫码报工，记录数量、重量、损耗。
10. 关键工序记录称重交接。
11. 需要质检的工序进入待质检。
12. 质检合格进入下一工序或成品库存。
13. 质检不合格生成返工、报废或让步通过。
14. 超标损耗自动生成审批。
15. 成品入库后创建出库单并冻结库存。
16. 打包称重，关联打包视频。
17. 录入快递信息，确认发货并扣减库存。
18. 通过母单、子工单或快递单号查询完整追溯。
19. 导出产量、损耗、库存、工资试算报表。

## 5. 功能模块

### 5.1 首页工作台

- 展示待处理数量：待入库、待拆分、待报工、待质检、待审批、待出库、视频失败。
- 展示关键指标：在制工单、今日产量、超标损耗、库存异常、返工数量。
- 按角色展示不同入口。

### 5.2 基础档案

- 客户档案：客户编号、名称、联系人、结算规则、数据权限范围。
- 物料档案：物料编码、名称、规格、计量单位、重量单位、是否贵重、损耗计价单位、当前单价。
- 物料价格历史：价格生效时间、失效时间、变更原因。
- 工序档案：工序编码、名称、工序类别、是否设备工序、是否计件、计件单价、是否记录损耗、标准损耗率、是否质检、是否交单审核。
- 工序模板：多道工序排序、默认工作项目、默认质检节点、默认损耗设置、设备编号要求。
- 员工档案：所属部门/班组、可操作工序、是否启用。
- 仓库档案：待加工、在制、半成品、成品、冻结、返工、报废、已发货。

### 5.3 客户订单

- 支持创建、编辑、提交、作废。
- 支持关联多个母单和多个出库单。
- 状态包含草稿、已确认、部分入库、生产中、部分发货、已完成、已作废。

### 5.4 来料入库与母单

- 扫描或录入快递单号。
- 登记入库日期、快递名称、快递单号、寄货人、收货人、拆箱签字、货品名称、客户、物料、数量、重量、加工要求、完成期限、照片和备注；现行手机收货要求加工要求与期限必填。
- 当前由手机上传拆包照片或短视频；录像机截取任务为后续备选，不作为收货确认前置。
- 确认入库后生成母单编码和客户所有库存。
- 异常来料需发起审批或标记待确认。

### 5.5 生产工单

- 支持按数量、重量或组合方式拆分子工单。
- 拆分总量不得超过母单可分配余额。
- 子工单生成后自动带出工序实例和单价/损耗率快照。
- 支持分配给员工、班组或工位。
- 报工必须按工序顺序执行，跳工序需权限。
- 抛光等人工工序需记录工作项目、开始时间、完成时间、完成情况和交单审核。
- 雕刻等设备工序需记录品类、机器编号、雕刻数量和操机签字。

### 5.6 PWA 移动作业端

- 手机浏览器访问，无需原生 App。
- 支持扫码识别母单、子工单、出库单。
- 操作工可查看我的任务、扫码报工、录入数量/重量/损耗。
- 质检员可查看待质检、扫码质检、发起返工/报废。
- 库管员可扫码查询库存和出库状态。

### 5.7 质检与返工

- 质检结果：合格、返工、报废、让步通过。
- 返工作为特殊工单类型处理，关联原工单、原工序和质检记录。
- 返工报工默认不计工资。
- 返工完成后必须复检或按规则关闭。
- 报废必须记录原因、责任归因和库存影响。

### 5.8 损耗管理

损耗按工序投入计算：

```text
本工序损耗重量 = 本工序投入重量 - 本工序产出重量 - 合理转移重量
允许损耗重量 = 本工序投入重量 × 标准损耗率
超标损耗重量 = max(0, 本工序损耗重量 - 允许损耗重量)
超标损耗金额 = 超标损耗重量 × 物料单价快照
```

一期只统计理论扣减金额，不实际扣工资。

### 5.9 库存管理

- 库存以客户、所有权、母单、子工单、物料、仓库、库存状态为核心维度。
- 所有库存变化必须生成库存台账。
- 库存余额由台账汇总或同步更新得出，不允许手工直接修改。
- 出库单创建后冻结库存，确认发货后扣减库存。
- 库存调整必须填写原因并审批。

### 5.10 出库管理

- 支持按客户、订单、母单、子工单选择成品。
- 创建出库单时冻结可用库存。
- 登记交货日期、客户、交货类目、交货数量、快递、经办人和备注。
- 打包称重时记录重量、包装信息和视频时间。
- 录入快递单号后确认发货。
- 发货确认后扣减库存并更新订单状态。

### 5.11 全链路追溯

查询入口：

- 母单编码。
- 子工单编码。
- 客户订单号。
- 入库快递单号。
- 出库快递单号。
- 二维码扫码。

追溯内容：

- 客户订单、来料记录、母单信息。
- 拆包照片/视频。
- 子工单、工序、报工、称重交接。
- 质检、返工、报废。
- 损耗记录和审批。
- 库存台账。
- 出库、交货类目、经办人、打包视频、快递信息。
- 操作日志。

### 5.12 工资试算与基础经营核算

- 数据来源为报工记录。
- 工序单价在工序实例创建时保存快照。
- 正常报工按合格数量计算。
- 返工报工默认金额为 0。
- 损耗扣减仅展示理论扣减，不进入正式工资。
- 支持按员工、班组、日期、工序导出；工资试算与确认保留快照，确认后形成基础应付，不产生银行代发或正式扣款。
- 每个客户协议选择按克、按件或雕刻／镶嵌／抛光分项计价，已入账账单保留报价快照，改价不追改历史。
- 按克、按件在来料确认后由财务生成月账单；按工序在该工序交付后计费，返工不重复计费。收款、核销与未收款分别可核对。
- 公司侧记录工资、消耗品采购及外协应付与付款；消耗品领用和固定资产折旧进入经营成本。折旧只进公司月度经营，客户来料库存不计为公司资产。
- 完整口径见业务规则，实际权限、字段和已提供查询见接口契约。经营结余不等同于净利润，收款不等同于加工收入。

## 8. 待业务确认事项

- 试点产品、试点工序、试点员工和试点车间范围。
- 母单拆分是否必须同时按数量和重量完全拆平。
- 各物料和工序的标准损耗率来源。
- 损耗责任按个人、班组还是管理人员归因。
- 哪些工序必须质检。
- 返工次数上限和超限审批人。
- 视频保存周期和存储位置。
- 标签尺寸、打印机类型和标签内容。
- 是否需要导入历史库存。
- 是否有现成 NVR、摄像头、扫码枪、打印机、电子秤型号。
