## 本段修复

- 标签页和来料拆单贴纸周围的界面颜色改回全站令牌。打印页本身仍是黑白、按毫米纸，不带品牌色。
- 客户未收条不再用暖金做金额背景，改为主操作色。财务明细金额右对齐，大金额可以换行。
- 设备读数消费和消费记录、登记入账映射在窄屏有卡片，消费按钮可以点到。模板概览不再被窄屏整表藏掉，仍在自己的容器里横向滚动。
- 「新建 POC」「导出清单」「记录 POC」没有实现，改为不可点击。
- 标签页原先不在任何角色菜单里，登录后到不了。新增 `V47__m3_label_menu.sql`，管理员、总经理、业务、收货和仓管可见，操作工不可见。内存菜单与探针、迁移索引一起更新。已有库需备份后受控执行 V47。
- 并发回放测试原来假定左侧线程先写完。先完成的一侧结果会被另一侧回放，断言改为两边结果相同。业务回放规则没有改。
- 生产构建被发货面板和证据夹具的类型错误挡住。发货数量、重量按表单文本交给原有确认逻辑；测试夹具补上已有文件类型。没有改发货规则。

## 服务端边界

| 身份 | 结果 |
|---|---|
| 管理员登录，公司范围 | 看到上面这一笔应付 |
| 请求头 `FINANCE_STATISTICIAN` + `ALL`，不带登录令牌 | 公司范围，应付相同 |
| 操作工登录 | 财务接口 403，菜单没有财务 |
| 未登录 | 403 |
| `FINANCE_STATISTICIAN` + `CUSTOMER_RANGE` 且客户范围为空 | 403 |
| 同一角色，客户范围 `1001` | 范围是客户集合，只含 1001，能看到归到该客户的外协 |
| 该身份再查客户 1002 | 403 |

本地没有现成的单客户财务登录账号。单客户和公司范围的财务角色用内存模式允许的请求头核对；管理员和操作工用真实登录会话。MySQL 默认关闭请求头身份，这组请求头不能当作生产授权。
