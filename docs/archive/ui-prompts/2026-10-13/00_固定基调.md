**归档说明（2026-10-13）**：本文保留历史执行提示，不作为当前开发指令或验收证明；现行唯一入口见 [项目核心](../../../00_项目核心.md)。
本文件保存 UI 特有的执行规范。工程分层、协作、工作区保护、测试、文档同步和提交门槛统一遵守 [AGENTS.md](../../../../AGENTS.md)，不在每个任务重复定义。设计理由见 [整体规划](../../ui/2026-10-13_26_ERP整体UI与多端设计规划.md)，当前任务与完成提交见 [任务入口](../../ui/2026-10-13_27_UI开发执行提示词.md)。

## 设计决定

- 定位：专业、清晰、克制的珠宝加工 ERP，办公管理与现场作业分别组织。
- 颜色：导航 `#17263C`；主操作 `#315FD1`；工作区 `#F3F5F9`；内容 `#FFFFFF`；边线 `#E2E7EF`；主字 `#17263C`；次字 `#617087`；品牌暖金 `#AE8A52`。
- 全站语义令牌管理颜色。暖金不用于大面积表格、主按钮和金额背景；禁止各模块自行定义另一套主题。第一版只做浅色工作区。
- 桌面正文 14px、标题 20–24px；手机正文与输入 16px。金额等宽数字、千分位、右对齐；明细两位小数并带单位。
- 间距用 4／8／12／16／24／32px；按钮与输入圆角 6px，内容区 10px。桌面标准行高 44px，必要时紧凑为 36px；手机点击目标至少 44px。
- 状态配文字：成功绿、处理中蓝、待办／警告橙、失败／逾期红、草稿灰。一套线性图标，重要操作有中文标签。
- 桌面：业务导航＋上下文页头＋筛选＋列表／详情。经营看板允许指标卡；日常单据页不堆装饰卡片、重复标题或说明大段。
- 手机：任务优先、单据卡片、单独详情和分步表单。核心动作不靠横滑桌面宽表格。底部入口为现有「工作台、现场作业、审批、更多」，按权限裁剪。
- 320、375、390、768、1024、1440px 均须正常；外层不横向溢出。保留键盘焦点、可读对比度、减少动态效果设置，重要内容不依赖悬停。
- 黑白标签与毫米纸张独立于应用皮肤，不把品牌色带进打印。

## UI 开发边界

- 核对前置任务实际代码和契约，仅执行当前任务，完成后等待下一段启动；不以归档施工说明代替当前实现。
- 沿用 Vue 3、TypeScript、Vite、自有 CSS 和 API 客户端。第一版不新增 UI 库、图表库、路由库或跨端工程；保留 `activeTab` 和菜单编码。APP／小程序仅在 UI-11 明确启动后验证。
- 复用 `AppShell`、`StatusBadge`、`NavIcon` 与业务类型，出现真实重复需求再抽组件，不提前创建无人调用的组件。
- 只重排表现和交互，不改变登录、业务状态机、计价、库存命令、扫码编码和打印协议；当前任务明确要求的后端授权与聚合除外。
- 运行页面不新增硬编码客户、单据、金额和日期。样例仅留在测试或隔离设计资料；接口未提供时明确尚不可用。
- 加载、无数据、失败、无权限、缺项分别反馈；保存失败保留输入，未实现动作不能做可点击空入口。
- 未定义账务语义先给代码证据和最小待确认问题，不能为填满看板发明计价、分摊、余额或授权规则。

## 已建立的单据模板与财务依赖

单据页以「页头与主动作 → 常用筛选 → 列表 → 选中详情」组织。宽屏可列表与详情并列，手机用卡片进入独立详情，返回保留筛选和选中状态；高级筛选与编辑表单按需展开。以 [来料页实际实现](../../../../frontend/src/features/m1/InboundWorkspace.vue) 和其行为测试为代表，后续模块保留真实加载、追溯、客户范围、证据、拆单、打印及错误处理，不能只复制样式。

UI-04、UI-05 已建立的财务读取授权、客户范围解析和只读六个月经营查询是后续任务的依赖。UI-06 已提供当前余额、客户未收排行和只读明细；不可用时仍不能用 0 或空数组伪装已经查过。UI-07 从实际服务及 [API 契约](../../../16_字段字典与API契约.md) 继续：公司、授权客户集合、单客户范围及工资／公司成本读取边界保持一致，查询不写账。

## 财务不可改变的口径

- `revenue` 为入账加工费净额，不是实收；`result` 为减去已记录成本后的经营结余，不是净利润。展示 `gaps`，缺项时标暂估。
- 客户账单 `receivedAmount` 为所选账单累计核销额，不是本月实收；应付 `paidAmount` 也不是本月实际付款。
- 选择月份只影响期间收入、成本和趋势；第一版余额与排行均为「截至当前」，返回实际 `asOf`。不实现或暗示历史月末回放。
- 客户来料数量／克重不是企业自有资产金额。公司折旧及未分配成本不自动摊给客户；客户结余不承诺相加等于公司结余。
- 后端权威计算金额；不对分页表或逐客户请求结果前端相加来冒充全量指标。只读查询绝不触发生成账单、工资、折旧或核销。
- 所有汇总、趋势、排行和明细须有服务端读取授权及相同客户范围。隐藏按钮、隐藏金额、传入 customerId 都不是授权。
- 第一版不做账龄、预算、银行余额、净利润、完整现金流、历史余额回放或新增成本分摊模型。
