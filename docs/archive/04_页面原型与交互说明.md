# 来料加工进销存与生产管理系统 页面原型与交互说明

**文档版本**：V2.0  
**文档定位**：产品原型、交互评审、前端开发依据  
**关联文档**：[01_PRD_产品需求文档](./01_PRD_产品需求文档.md)

---

## 1. 设计原则

- 一线操作优先少录入、强校验、扫码驱动。
- PC 后台用于管理、审核、查询和配置。
- PWA 移动网页用于现场扫码、报工、质检和库存查询。
- 每个业务页面必须显示当前状态、下一步动作和异常提示。
- 关键操作必须有二次确认和操作日志。
- 页面不直接修改库存余额，只触发业务单据。

## 3. PC 后台页面

### 3.1 首页工作台

适用角色：总经理、业务员、车间组长、质检员、库管员、统计人员。

页面区域：

| 区域 | 内容 |
|---|---|
| 待办卡片 | 待入库、待拆分、待报工、待质检、待审批、待出库、视频失败 |
| 指标卡片 | 今日产量、在制工单、超标损耗、返工数量、库存异常 |
| 快捷入口 | 新建订单、来料收货、工单拆分、库存查询、追溯查询 |
| 异常列表 | 损耗超标、视频失败、库存不足、返工超限 |
| 业务调度队列 | 业务单号、对象/客户、当前节点、责任人、状态、下一动作 |
| 焦点工单侧栏 | 当前阻断工单、称重交接、产出进度、扫码报工和称重交接入口 |
| 证据链健康度 | 业务单据、称重记录、视频证据、操作审计完整性 |
| 软硬件兜底 | NVR、标签打印、扫码、电子秤 POC 状态和人工兜底动作 |
| 模块 API 契约 | 已接业务命令、样例数据来源、未交付边界 |

M3.49 首屏结构：

| 区块 | 设计要求 |
|---|---|
| 流程链路 | 左侧固定展示收货、称重、派工、质检、入库、证据六个节点，显示数量和阻断状态 |
| 今日单据池 | 中部主表优先展示 P0/P1 阻断、母单、工单和质检单，字段必须包含优先级、单号、类型、业务对象、节点、责任人、证据/风险和动作 |
| 当前处理单 | 右侧展示当前工单/母单/库存批次、负责人、进度、证据状态和三个以内的主操作 |
| 操作员待办 | 明确展示补称重、视频失败、损耗审批等必须处理的真实任务，不用泛泛指标替代 |
| 焦点任务 | 首页第二层展示焦点工单、称重交接和质检门禁，作为主表的辅助详情，不抢占主表位置 |
| 视觉风格 | 采用现场控制台式 ERP/MES 工作台：浅色导航、浅色业务区、清晰表头、稳定状态色、三栏作业结构，避免演示稿式大面积说明卡片 |

M3.53 核心业务页交互基线：

| 页面 | 主交互 | 焦点对象 | 动作链 |
|---|---|---|---|
| 生产工单 | 点击今日工单池行后高亮选中，不再只展示默认工单 | 右侧显示工单编码、客户、物料、当前工序、负责人、称重阻断、工资口径和进度 | 扫码进站、工序报工、称重交接、送检入账 |
| 质检返工 | 点击今日质检池行后高亮选中，冻结/返工/放行/损耗动作均围绕当前质检单 | 右侧显示质检单、工单、工序、缺陷和关联损耗审批 | 冻结异常库存、返工派发、返工报工、复检放行、损耗审批 |
| 库存追溯 | 点击客户库存池行后高亮选中，台账和证据锚点围绕当前批次 | 右侧显示批次、客户、物料、库位、数量重量、冻结量和最近台账 | 客户权属、批次余额、台账明细、证据归档、售后复核 |

M3.54 UI 视觉纠偏基线：

| 区块 | 设计要求 |
|---|---|
| 全局外壳 | 侧栏、顶部状态条、页头和模块区统一为浅色高密度 ERP/MES 风格，不再使用重暗色演示控制台视觉 |
| 首页首屏 | 首屏必须同时看到今日单据池和当前处理单，指标卡、说明文案不得挤占主表空间 |
| 表格 | 主表采用固定表头、清晰行分隔、选中态和 hover 态，业务对象、责任人、证据风险和下一动作必须可读 |
| 详情侧栏 | 当前处理对象、关键字段、动作按钮和操作链按主从关系展示，避免把证据链卡片堆成展示页 |
| 状态色 | 绿色、蓝色、黄色、红色用于状态区分，低饱和显示，避免单一青色或大面积渐变造成视觉疲劳 |

交互规则：

- 按角色展示不同待办。
- 点击待办卡片进入对应列表并自动带筛选条件。
- 异常列表默认按严重程度和时间排序。
- 首页首屏优先展示“今天该处理什么”，说明性文字不得压过业务队列、工单详情和动作按钮。
- 已完成、样例、POC、待开发必须在页面上明确区分，避免把评审页面误判为完整交付系统。
- 参考 ERPNext/Frappe、Odoo Manufacturing、InvenTree 等成熟开源系统的信息组织方式，但只有经过 POC 和许可证评估后才能进入二开或集成范围。

### 3.2 客户档案

入口：基础档案 -> 客户。

字段：

- 客户编码、客户名称、联系人、电话、地址、结算备注、启用状态。
- 数据权限范围。

按钮：

- 新增、编辑、停用、导入、导出。

校验：

- 客户编码唯一。
- 已有关联单据的客户不可删除，只能停用。

### 3.3 物料档案

字段：

- 物料编码、名称、规格、数量单位、重量单位、是否贵重、损耗计价单位、当前单价、启用状态。

扩展页签：

- 价格历史。
- 关联工序损耗率。

校验：

- 物料编码唯一。
- 单价变更必须写入价格历史。
- 已用于单据的物料不可删除。

### 3.4 工序与工序模板

工序字段：

- 工序编码、名称、类型、工序类别、是否设备工序、是否计件、计件单价、是否记录损耗、标准损耗率、是否需要质检、是否需要交单审核、启用状态。

工序模板字段：

- 模板名称、适用物料/产品、工序顺序、默认工作项目、默认质检节点、默认损耗率、默认单价、设备编号要求。

现场补充：

- `抛光` 工序页面必须能录入工作项目、开始时间、完成时间、完成情况和交单审核。
- `雕刻` 工序必须纳入模板，可配置机器编号、品类和操机签字要求。

交互：

- 模板明细支持拖拽排序。
- 保存模板前校验工序顺序不可重复。
- 工序单价变更写入历史，新工单使用新单价，旧工单不变。

### 3.5 客户订单列表与详情

列表字段：

- 订单号、客户、状态、预计交期、母单数量、在制数量、已发货数量、创建人。

详情页签：

- 基本信息。
- 关联母单。
- 关联子工单。
- 出库记录。
- 操作日志。

按钮：

- 新建、编辑、提交、作废、查看追溯。

校验：

- 已进入生产的订单关键字段修改需记录日志。
- 作废已有关联库存的订单需走异常流程。

### 3.6 来料入库与母单页面

列表字段：

- 母单编码、客户、入库日期、快递名称、入库快递单号、寄货人、收货人、拆箱签字、货品名称、物料、数量、数量单位、重量、状态、拆包视频状态、来源登记表、原表行号、纸质序号、创建时间。

详情页签：

- 来料信息。
- 现场签收登记。
- 物料明细。
- 原始登记来源，包含来源表、sheet、行号和导入批次；人工录入时可为空。
- 拆包记录。
- 子工单。
- 库存台账。
- 视频附件。
- 操作日志。

核心按钮：

- 扫码收货、开始拆包、确认入库、打印母单标签、拆分工单、重新截取视频、人工上传视频。

关键校验：

- 快递单号不可重复。
- 未确认客户和物料不得确认入库。
- 拆箱签字缺失时不得直接确认入库，除非主管审批放行。
- 数量必须同时填写单位；默认 `件`，但物料配置为 `颗/条/批` 时必须按配置带出。
- 异常审批未处理前不得拆分工单。
- 确认入库后不得直接修改数量和重量，必须走更正或调整。

异常提示：

- “该快递单号已关联母单：xxx”
- “当前母单存在待审批异常，暂不可拆分工单”
- “视频截取失败，可重试或人工上传”

### 3.7 生产工单页面

列表字段：

- 工单编码、母单、客户、工单类型、当前工序、工序类别、工作项目、品类、机器编号、分配人、状态、计划数量、数量单位、计划重量、返工次数、交单审核、来源登记表、原表行号、纸质序号。

详情页签：

- 工单信息。
- 物料明细。
- 工序实例。
- 报工记录。
- 工序日记录。
- 设备产量记录。
- 称重交接。
- 质检记录。
- 损耗记录。
- 库存台账。
- 日志。

核心按钮：

- 拆分子工单、分配、改派、打印标签、作废、查看追溯。

校验：

- 子工单拆分总量不得超过母单可分配余额。
- 已开工工单不得直接删除。
- 已报工工序不得直接修改顺序。
- 抛光报工缺少开始时间、完成时间或完成情况时，不得提交交单审核。
- 雕刻报工缺少机器编号、品类或操机签字时，不得进入设备产量统计确认。
- 抛光日报的姓名、日期为表头级上下文，批量导入时必须展开到每条工作项目行；工作项目行未填纸质序号时仍按原始行号进入预检。
- 雕刻登记按机器行统计，空白日期/客户/品类应继承本序号组上下文，不能直接当作无效行；进入新序号组后必须重置上下文。
- 报工数量必须带单位，默认 `件`，并与工序模板和物料单位一致。

### 3.8 工单拆分弹窗

字段：

- 母单可用数量、可用重量。
- 拆分方式：按数量、按重量、手工明细。
- 子工单行：数量、重量、工序模板、备注。

按钮：

- 自动均分、添加行、删除行、生成子工单。

校验：

- 拆分合计不可超过可用余额。
- 重量误差超过系统参数时阻止提交或要求权限确认。
- 必须选择工序模板。

### 3.9 质检返工页面

待质检列表字段：

- 工单编码、母单、工序、员工、报工数量、报工重量、待检时间。

质检表单字段：

- 质检结果、合格数量、不合格数量、原因、处理方式、照片、备注。

处理方式：

- 合格。
- 返工。
- 报废。
- 让步通过。

交互：

- 选择返工时必须选择返工目标工序和原因。
- 选择报废时必须填写报废数量、重量和责任归因。
- 让步通过需要权限或审批。

### 3.10 库存管理页面

页面：

- 实时库存。
- 库存台账。
- 库存调整。
- 冻结库存。

实时库存筛选：

- 客户、所有权、母单、工单、物料、仓库、库存状态。

库存台账字段：

- 时间、来源单据、客户、物料、数量、重量、来源仓库/状态、目标仓库/状态、操作人。

交互规则：

- 库存余额无编辑入口。
- 调整库存必须创建调整单。
- 点击台账可跳转来源单据。

### 3.11 出库管理页面

列表字段：

- 出库单号、客户、交货日期、交货类目、交货数量、数量单位、状态、快递公司、快递单号、纸质快递栏原文、经办人、出库重量、视频状态、来源登记表、原表行号、纸质序号、发货时间。

详情页签：

- 基本信息。
- 交货登记。
- 出库明细。
- 打包记录。
- 视频附件。
- 库存台账。
- 操作日志。

按钮：

- 创建出库、冻结库存、开始打包、确认发货、取消出库、打印出库标签、重试视频。

校验：

- 出库数量不得超过成品可用库存。
- 快递单号不可重复。
- 经办人缺失不得确认发货。
- 交货类目和交货数量必须与出库明细一致。
- 交货数量单位必须与库存明细单位一致；纸质表原始“快递”栏要保留，导入后再拆分快递公司和单号。
- 已发货单据不可直接回滚。

### 3.12 审批管理页面

列表字段：

- 审批编号、审批类型、来源单据、申请人、状态、创建时间、当前处理人。

详情内容：

- 审批原因、业务数据快照、附件、审批历史。

按钮：

- 同意、驳回、转交、查看来源单据。

规则：

- 审批通过或驳回必须写入审批记录。
- 审批结果反写业务单据状态。

### 3.13 全链路追溯页面

入口：

- 顶部搜索框。
- 母单详情。
- 工单详情。
- 出库详情。
- PWA 扫码。

查询条件：

- 母单编码、子工单编码、客户订单号、入库快递单号、出库快递单号、客户。

展示方式：

- 顶部摘要：客户、母单、物料、数量、重量、当前状态。
- 时间线：来料、拆包、入库、拆分、报工、称重、质检、返工、损耗、入库、出库、视频。
- 关联表格：工单、库存台账、质检、损耗、媒体、审批。

交互：

- 时间线节点可展开详情。
- 视频节点可播放或下载。
- 台账节点可跳转来源单据。

### 3.14 工资试算与报表

工资试算筛选：

- 日期、员工、班组、工序、客户、母单。

字段：

- 员工、工序、合格数量、单价快照、计件金额、返工数量、理论扣减、来源报工。

规则：

- 返工金额默认 0。
- 损耗扣减只显示理论值。
- 导出需记录操作日志。

## 4. PWA 移动作业端

### 4.1 登录与首页

页面内容：

- 我的待办。
- 扫码按钮。
- 我的报工。
- 待质检。
- 库存查询。

交互：

- 登录后根据角色展示入口。
- 网络异常时提示重试，不直接清空表单。

### 4.2 扫码页

支持码类型：

- 母单二维码。
- 子工单二维码。
- 出库单二维码。
- 快递单号。

识别后跳转：

| 类型 | 跳转 |
|---|---|
| mother_order | 母单详情/库存查询 |
| work_order | 报工或工单详情 |
| outbound_order | 出库详情 |
| express_no | 收货或追溯 |

异常：

- 无权限：提示“当前账号无权操作该单据”。
- 无效码：提示“未识别的二维码内容”。
- 非当前工序：提示“当前工序不可报工”。

### 4.3 操作工报工页

字段：

- 工单编码、当前工序、物料、计划数量、计划重量、上一工序产出重量。
- 完成数量、产出重量、损耗重量、备注。

按钮：

- 提交报工、保存草稿、查看追溯。

校验：

- 完成数量和产出重量必填。
- 损耗超标时提示将触发审批。
- 返工报工页面明确显示“返工默认不计工资”。

### 4.4 称重交接页

字段：

- 交接类型、交出人、接收人、投入重量、产出重量、包装重量、照片/附件、备注。

交互：

- 可从报工页进入。
- 关键工序未填写称重交接时阻止提交。
- 二期可扩展电子秤自动读取。

### 4.5 质检页

字段：

- 工单、工序、报工数量、报工重量。
- 质检结果、合格数量、不合格数量、原因、照片、备注。

按钮：

- 合格、返工、报废、让步通过。

校验：

- 返工必须选择返工目标工序。
- 报废必须填写数量、重量和原因。

### 4.6 库存查询页

查询方式：

- 扫码查询。
- 输入母单/工单/物料。

展示：

- 当前客户、所有权、仓库、库存状态、数量、重量。
- 最近 10 条库存台账。

## 5. 通用交互规范

### 5.1 状态展示

- 所有主单据列表必须显示状态标签。
- 异常状态使用明确文本，不只靠颜色。
- 视频、审批、库存冻结等异步状态需要显示进度。

### 5.2 二次确认

以下操作必须二次确认：

- 单据作废。
- 库存调整提交。
- 发货确认。
- 视频替换。
- 标签补打。
- 报工更正。

### 5.3 表单草稿

PWA 以下表单需要草稿保护：

- 报工。
- 质检。
- 称重交接。

### 5.4 错误提示

错误提示必须包含：

- 发生了什么。
- 为什么不能继续。
- 用户下一步可以做什么。

示例：

```text
当前工单还未完成上一道工序，不能报工。
请联系车间组长确认工序状态，或扫描正确的子工单标签。
```

---

## 6. 页面验收标准

- 业务员能完成客户订单创建并查看关联母单。
- 收货员能扫码收货、拆包、确认入库、打印母单标签。
- 车间组长能拆分子工单、分配任务、打印标签。
- 操作工能用 PWA 扫码报工并提交称重交接。
- 质检员能处理合格、返工、报废、让步通过。
- 库管员能创建出库、冻结库存、确认发货。
- 管理员能通过追溯页看到完整业务链路。
- 财务/统计能导出工资试算和损耗报表。
