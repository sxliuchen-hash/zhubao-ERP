## 5. M2 当前推进记录

### 5.1 已完成

- 新增 `样例库` 页面，用于管理演示、测试和验收样例。
- 新增 `软硬件联动` 页面，用于管理摄像头、标签打印、扫码、PWA、电子秤的一期状态和兜底。
- 改进 UI 视觉层次，将首页和软硬件页调整为高密度 ERP 工作台：侧栏状态、业务日期、异常数、证据完整率、核心链路、在制工单、设备兼容矩阵和兜底边界集中呈现。
- 深化核心业务页面：来料接收控制台、生产工单调度台、质检返工处理台、库存与追溯证据台、移动现场作业台。
- 新增集中样例数据：入库检查点、入库异常、工位负载、称重交接、质检指标、损耗审批、库存台账明细、追溯证据、PWA 能力边界和离线草稿。
- 新增前端业务工作台 API 映射层，来料、生产、质检、库存、PWA 页面采用 API 优先、静态样例兜底的加载策略。
- 新增样例与硬件数据模型，并补充测试覆盖。
- 新增 [15_样例与软硬件联动管理.md](./15_样例与软硬件联动管理.md)。
- 新增后端样例库 API：`/api/samples/scenarios`、`/api/samples/summary`。
- 新增后端软硬件联动 API：`/api/hardware/devices`、`/api/hardware/integration-tasks`、`/api/hardware/summary`。
- 新增后端核心业务工作台 API：`/api/business/workspaces/inbound`、`/api/business/workspaces/production`、`/api/business/workspaces/quality`、`/api/business/workspaces/inventory`、`/api/business/workspaces/mobile`、`/api/business/workspaces/summary`。
- 将后端业务工作台样例拆分为 `BusinessWorkspaceSeedData`、`BusinessWorkspaceRepository` 和 `InMemoryBusinessWorkspaceRepository`，为 M3 MySQL repository 替换预留边界。
- 新增 MySQL 表结构草案：`V2__m2_sample_hardware.sql`。
- 新增工作台字段契约 SQL 草案：`V3__m2_business_workspace_contract.sql`。
- 新增 [16_字段字典与API契约.md](./16_字段字典与API契约.md)，用于 M3 数据库和前后端联调基线。
- 根据页面评审反馈完成第一轮 UI 产品化重构：将首页从卡片式原型升级为生产追溯指挥台，新增全局状态、风险信号、追溯筛选、责任分布、统一状态色和高密度表格样式。
- 来料、生产、质检、库存页面新增业务上下文筛选条，明确业务对象、阻断规则、证据策略、库存归属和返工口径，提升评审时对现场流程的可读性。
- 新增配置基线后端 API：`/api/configuration/baseline/summary`、`/system-parameters`、`/code-rules`、`/role-permissions`、`/process-templates`、`/warehouse-states`、`/video-parameters`、`/components`、`/backup-policies`。
- 新增前端 `配置基线` 页面，覆盖系统参数、编码规则、角色权限、工序模板、仓库状态、视频参数、开源组件和备份策略。
- 新增配置基线 MySQL 表结构草案：`V4__m2_configuration_baseline_contract.sql`。
