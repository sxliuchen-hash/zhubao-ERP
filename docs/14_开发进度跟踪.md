# 开发进度

**更新日期**：2026-10-09

当前在基础版本 `baseline-m3.138` 之后的分支 `dev/after-m3.138` 上整理界面和文档。

| 事项 | 状态 |
|---|---|
| 来料、报工、质检、出库、退货、损耗审批写库存台账 | 已有命令和测试 |
| 登记表预检、确认、显式入账 | 已有 |
| 登录、账号、菜单、客户范围 | 已有，仍不是完整身份系统 |
| 前端死代码和只读说明接口 | 已去掉页面里未使用的指标和流程常量，以及硬件适配/协议说明接口、`GET /api/m0/status` |
| 工作台单据 | 来料、生产、质检、库存、审批和首页只显示接口返回的单据；接口没有数据或不可用时显示空列表和失败原因。前端不再保留另一份母单、工单和库存样例 |
| 配置页 | 系统参数、角色和工序模板不再放在页面上。页面只保留登录、账号和客户范围 |
| 客户交付版本 | 尚未形成 |
| 标签打印 | 按标签纸毫米尺寸单独出黑白标签。现场贴纸从母单或子单带出验证码、客户、加工要求、期限和单号。预览不再用深色底和金色角标，打印不带侧栏和表单 |
| 手机现场采集 | 第 1 段已接上：手机收货页可识别快递单号，生成带加工要求和期限的母单，并上传拆包短视频。来料页可打开该母单的视频。实时扫码优先用浏览器 BarcodeDetector，没有则用内置 ZXing；摄像头打不开时改拍面单照片 |
| 现场作业收口 | 计划见 [25_现场作业收口计划.md](./25_现场作业收口计划.md)。第 1 到第 4 段和第 5 段进度一览已落地。客户账单已按经营核算落地，不做总账 |
| 财务经营核算 | 财务菜单可维护客户协议、生成加工费、登记收款、确认月度工资、管理消耗品和固定资产、查看应付和月度经营。客户来料库存仍在库存页。财务统计可记账，操作工不能收款 |
| 作业台布局 | 侧栏可收成图标。手机宽度使用底部导航，双栏改成上下排列，宽表格在屏内横向滑动 |
| 登录、用户和运维 | 未登录进入登录页。配置页可新建、修改、启停和解锁账号，并可下线已存储内容。运维页显示硬件在线、磁盘和附件占用 |
| ERP 整体 UI 与多端规划 | 已形成 [26_ERP整体UI与多端设计规划.md](./26_ERP整体UI与多端设计规划.md) 及交互概念示意。覆盖统一视觉和页面模板、财务指标口径、手机岗位任务流、APP／小程序适配及分段验收；尚未实施业务页面替换。财务聚合需先补查询授权和客户范围 |
| UI 分段开发提示词 | 已准备 [27_UI开发执行提示词.md](./27_UI开发执行提示词.md)、共同基调、UI-01 至 UI-11 任务文件及仓库内参考图。用户可切换模型逐段执行 |
| UI-01 统一主题 | 全站语义色、按钮、焦点、金额右对齐已落地。侧栏结构、业务页面布局和接口未改。标签打印仍是独立黑白文档 |
| UI-02 外壳与导航 | 电脑侧栏为深蓝灰，入口按六个业务分组展示。手机底部为工作台、现场作业、审批、更多。分组不新增权限 |
| UI-03 来料代表页 | 来料页按筛选、列表和详情组织。电脑保留表格，手机用卡片进入详情。加工要求未从接口返回时显示打开后核对，不估算金额 |
| UI-04 财务读取授权 | 财务 GET 区分客户读取和公司成本读取。客户范围不能靠空参数查看全公司工资、折旧和应付 |
| UI-05 经营聚合 | 只读接口返回选择月经营结果和六个月趋势。当前余额与客户排行为空。查询不生成账单、工资或折旧 |

历史里程碑记录在 [archive/14_开发进度跟踪.md](./archive/14_开发进度跟踪.md)。
