## 1. 当前范围

来料加工生产管理，主线为 **收货 → 母单／拆单 → 标签 → 分批交工 → 质检／返工／放行 → 发货 → 库存、财务与证据追溯**。保留 `App.vue` 原 17 页及依赖，日常入口归并为工作台、订单、生产／质量、库存、客户、财务和审批；低频能力按需打开。桌面、手机共用服务与有效权限。

当前不扩展完整客户订单、自有产品销售、实物盘点、完整成本会计、小程序或新硬件集成。安卓已有 debug 容器，正式签名与当前版本全链验收未完成；网页发布不等于 APK 更新或客户交付。

## 2. 现行架构与约束

- Vue 3／TypeScript／Vite，Java 17／Spring Boot 3 模块化单体；领域内保持 `domain/app/infra/web`。不按 `m1`、`sample` 等旧命名判定弃用。
- 本地默认内存，MySQL 下业务、库存、财务等默认 JDBC；审批、附件元数据等仍有独立开关，Compose 显式覆盖。只开 profile 不代表全部数据持久化；登录会话随账号仓储保存。
- 正式工作台默认 `LIVE`，空库为空；显式 `zhubao.business.workspace.demo-enabled=true` 才读独立 `DEMO` 快照，两者不合并。
- 单据在 `BusinessDocumentRepository`，库存经 `StockLedgerService`，跨仓储用 `BusinessWorkUnit/WorkSession` 同次提交。查询、说明、上传及 100% 进度不写交工、库存或工资。
- 母／子单号是业务身份，运单只是检索线索；多候选人工选择。稳定客户 ID 授权，历史名称仅唯一映射时生效。`CUSTOMER_RANGE` 空名单拒绝；其他岗位仍按本人、班组／部门范围，空组织不扩大权限。
- 桌面、手机使用同一菜单及 `effectivePermissions`，服务端逐请求鉴权；总经理显式清单。管理员保存账号并审计，敏感升权双人复核待定。
- 附件是原件＋数据库元数据／引用，成套备份；MySQL 签名密钥至少 32 字符随机值。生产禁用开发请求头身份。下线不删除原件，管理对账不自动清理文件。
- 迁移 append-only，保留历史表、seed 与原文校验和。代码归档不删表、不清数据。PWA、条件装配、升级、备份及设备依赖不能因没有独立菜单而删除。

### 已有能力与实际边界

10-27 已发布需求：修复报工／进度／改单控制器重建账号时丢失顶岗与组织信息，业务管理按已授权工种正常报工，仍须具有“报工”顶岗权限。订单中心桌面／手机显示原母单建单人，管理员可从详情“更多操作 → 母单编辑与删除”修改客户、货品和备注或删除至回收站。换客户仅限无拆单、交工、质检、改单及财务等下游事实的母单；逐条冲正有效收货并按新归属入账，支持多材质、零重量、事务回滚、版本冲突和请求回放。等待母单行锁后，母单版本和下游存在性均使用锁定读，避免 MySQL 旧事务快照放过并发保存或漏读新拆单。流转页新增仅管理员可读的母子单／执行轮次操作日志，删除和恢复也留下维护记录；历史缺失时间或人员不补造。相关验证和实际发布事实见上文。接口见 [API 契约](./16_字段字典与API契约.md#ordermaintenancecontroller)。

| 链路 | 当前实现与边界 |
|---|---|
| 收货与主数据 | 运单可关联多母单，可无运单建单；客户／材质可维护。多材质收货逐行入账、拆单按来源分配；同母单数量单位须相同，单张子单继续限制一种材质。加工要求模板用于建单要求文字，不新增工序或计费。尚未报工、质检、发货、改单或记账的整单生产可以撤销，恢复为待安排并留下调整记录；已出的整单贴纸作废，库存不改。 |
| 报工与分批交工 | 五档 0／30／60／90／100 只记进度，100% 仍待交工。同单分批记数量，下道只处理已到达数量；末道交齐后可零数量补总重量，未称重不开放质检。批次与全量完成事实分开，锁保护并发限额，失败整批回滚，原编号可回放；中间批次不伪造库存台账，工序收费仍按一次完成。 |
| 改单与管理员维护 | 改单草稿、财务逐次确认、差额／红字、生效版本和执行轮次已有主路径；在途批次阻止改路线生效。子单加工要求可直接保存并留下调整记录，不经财务审批；期限、路线和费用仍走改单。管理员维护有请求号、旧快照和调整记录事务保护；只允许符合条件的未拆单母单通过反向原收货＋新收货更正数量重量。已有账务事实不直接覆盖。回收／恢复隐藏单据，不冲销库存、财务、文件或外部打印。 |
| 库存 | 公司料、客户备料、加工库存与流水分区；小数和单位按来源展示，公司料总览按单位分开，未领用／已领用不混算。寄存待核、从备料建单已通过 JDBC 隔离链路核验；冻结、冲正与真实业务抽样仍待验收；未称量裸石只能待核。公司料领用不是消耗或成本核销。 |
| 打印 | 标签有版本与实例，快照冻结模板、份数及二维码。厂内纸张按 40×30 mm；旧 60×40 基线在生成和出纸时改为 40×30。多工位／队列各自领取。失败任务可直接取消后再提交；已入队或出纸不明仍须核纸，已领取任务不可改派。`SPOOLED` 只表示送入系统队列。按单据打开维护或在标签页连续提交时，贴纸内容没变只保留最新一批的办理信息，不再把每一笔批次详情摊开；内容变化才另留一批。按任务编号仍可单独打开旧任务。 |
| 附件 | 原件原子发布、用途与清晰度签名、流式读取和单段 Range；文档包、附件及证据双列表分页筛选，图片缩略／轻量预览、视频封面及可视区懒加载已发布。管理审计失败不拖垮业务列表。历史证据编号误用运单号的旧记录未改写。 |
| 工作台与界面 | 轻任务独立于工序／库存，可选客户及母单，按创建／指派身份授权。订单 Q1、共享详情与动作容器、跨端导航及信息分层已发布；草稿和结果未知时保留原请求，刷新失败不重复提交业务。手机拆单的数量和重量可直接输入；浏览器扫码会请求连续对焦，并缩小实时解码，避免预览被卡住。 |
