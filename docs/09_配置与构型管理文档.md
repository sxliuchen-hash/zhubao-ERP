## 1. 管理目标

配置与构型管理用于确保系统从试点到正式上线的配置可追溯、可复现、可审计。

当前 M2.2 已落地只读配置基线：

- 后端 API：`/api/configuration/baseline/*`。
- 前端页面：`配置基线`。
- SQL 草案：[V4__m2_configuration_baseline_contract.sql](../backend/src/main/resources/db/mysql/V4__m2_configuration_baseline_contract.sql)。
- 代码基线：[ConfigurationBaselineService.java](../backend/src/main/java/com/zhubao/erp/configuration/app/ConfigurationBaselineService.java)。

注意：当前为评审和 M3 迁移基线，不开放生产编辑。正式可编辑前必须补齐权限、审批、审计日志和历史版本。

覆盖范围：

- 系统参数。
- 编码规则。
- 角色权限。
- 工序模板。
- 损耗率。
- 计件单价。
- 仓库和库存状态。
- 视频参数。
- 标签模板。
- 环境配置。
- 开源组件版本。
- 许可证清单。
- 备份与恢复策略。

## 2. 配置分级

| 等级 | 类型 | 示例 | 变更要求 |
|---|---|---|---|
| C1 | 业务关键配置 | 损耗率、计件单价、库存状态、审批阈值 | 需审批，保留历史 |
| C2 | 运行参数 | 视频缓冲秒数、导出限制、扫码前缀 | 管理员可改，保留日志 |
| C3 | 展示配置 | 列表字段、标签模板、报表列 | 记录版本 |
| C4 | 环境配置 | 数据库、对象存储、NVR 地址 | 运维变更记录 |
| C5 | 开源组件 | 框架、库、工具版本 | 版本基线和许可证确认 |

## 3. 系统参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `system.code.prefix` | `JG` | 二维码和业务编码系统前缀 |
| `weight.precision` | `3` | 重量小数位 |
| `quantity.precision` | `3` | 数量小数位 |
| `split.weight.tolerance` | `0.02` | 工单拆分重量误差阈值，单位按物料配置 |
| `loss.approval.enabled` | `true` | 超标损耗是否触发审批 |
| `rework.max.count` | `2` | 返工次数上限 |
| `video.buffer.seconds` | `5` | 视频截取前后缓冲秒数 |
| `video.retry.max` | `3` | 视频截取最大重试次数 |
| `export.max.rows` | `50000` | 单次导出最大行数 |
| `inventory.negative.allowed` | `false` | 一期默认不允许负库存 |
| `pay.formal.enabled` | `false` | 一期不启用正式工资 |

## 4. 编码规则

### 4.1 编码原则

- 编码唯一。
- 编码可读。
- 编码不承载敏感信息。
- 编码生成后不可修改。
- 作废单据编码不复用。

### 4.2 建议格式

| 对象 | 格式 | 示例 |
|---|---|---|
| 客户订单 | `ORD-YYYYMMDD-流水号` | `ORD-20260706-001` |
| 母单 | `CC-YYYYMMDD-流水号-客户简称` | `CC-20260706-001-JL` |
| 子工单 | `母单编码-ZD流水号` | `CC-20260706-001-JL-ZD001` |
| 返工工单 | `原工单编码-FG流水号` | `CC-20260706-001-JL-ZD001-FG001` |
| 质检单 | `QC-YYYYMMDD-流水号` | `QC-20260706-001` |
| 损耗单 | `LS-YYYYMMDD-流水号` | `LS-20260706-001` |
| 出库单 | `OUT-YYYYMMDD-流水号` | `OUT-20260706-001` |
| 库存台账 | `STK-YYYYMMDD-流水号` | `STK-20260706-001` |
| 审批单 | `APR-YYYYMMDD-流水号` | `APR-20260706-001` |

## 5. 角色权限基线

| 角色 | 权限范围 |
|---|---|
| 系统管理员 | 用户、角色、菜单、参数、字典、日志 |
| 总经理/负责人 | 全部业务数据、审批、报表、追溯 |
| 业务员/客服 | 客户、订单、进度、出库状态 |
| 收货员 | 来料入库、母单标签、拆包视频 |
| 车间组长 | 工单拆分、分配、返工处理、本班组数据 |
| 操作工 | 本人任务、扫码报工、称重交接 |
| 质检员 | 待质检、质检记录、返工/报废发起 |
| 库管员 | 库存查询、出库、打包、库存调整申请 |
| 财务/统计 | 报表、工资试算、导出 |

敏感权限：

- 库存调整。
- 报工更正。
- 视频替换。
- 标签补打。
- 单据作废。
- 单价修改。
- 损耗率修改。

## 6. 工序模板配置

### 6.1 工序配置项

| 配置 | 说明 |
|---|---|
| 工序名称 | 如串制、打磨、抛光、质检、包装 |
| 是否计件 | 是否进入工资试算 |
| 计件单价 | 保存历史，工单创建时快照 |
| 是否记录损耗 | 是否要求录入损耗 |
| 标准损耗率 | 工单创建时快照 |
| 是否必须质检 | 报工后是否进入待质检 |
| 是否必须称重交接 | 关键工序控制 |

### 6.2 模板变更规则

- 模板变更只影响新建工单。
- 已生成的工序实例不随模板变更自动变化。
- 模板启停必须记录日志。

## 7. 损耗率与计件单价

### 7.1 损耗率

配置维度建议：

```text
客户 + 物料 + 工序 + 产品类型
```

一期可简化为：

```text
物料 + 工序
```

变更规则：

- 损耗率变更必须保留历史。
- 工序实例创建时保存损耗率快照。
- 历史工单不因损耗率变更而重算，除非走专门重算流程。

### 7.2 计件单价

配置维度建议：

```text
工序 + 产品类型 + 难度等级
```

一期可简化为：

```text
工序
```

规则：

- 单价变更必须保留历史。
- 工序实例创建时保存单价快照。
- 返工报工默认不计工资。
- 一期工资试算不正式发放。

## 8. 仓库与库存状态

### 8.1 仓库基线

| 仓库 | 说明 |
|---|---|
| 待加工来料仓 | 客户来料确认入库后进入 |
| 在制仓 | 子工单加工中 |
| 半成品仓 | 中间状态，可按业务启用 |
| 成品仓 | 质检通过后待发货 |
| 冻结仓 | 创建出库单后冻结 |
| 返工品仓 | 返工中或待返工 |
| 报废品仓 | 报废物料 |
| 已发货 | 逻辑状态，不一定对应实体仓 |

### 8.2 状态变更规则

- 来料入库：外部 -> 待加工。
- 拆分工单：待加工 -> 在制。
- 完工入库：在制 -> 成品。
- 创建出库：成品 -> 冻结。
- 确认发货：冻结 -> 已发货。
- 返工：成品/在制 -> 返工。
- 报废：对应状态 -> 报废。

## 9. 视频参数

| 配置 | 默认 | 说明 |
|---|---|---|
| 视频缓冲秒数 | 5 | 截取前后额外时间 |
| 最大重试次数 | 3 | 自动截取失败重试 |
| 默认格式 | mp4 | 业务片段格式 |
| 保存周期 | 待确认 | 按业务和容量确定 |
| 上传大小限制 | 待确认 | 人工上传视频大小 |
| 摄像头绑定 | 工位/业务点 | 拆包台、打包台、异常处理台 |

规则：

- 视频删除或替换需要权限和日志。
- 视频失败不阻止业务继续，但追溯中显示证据状态。
- 视频文件不存数据库，只存路径和元数据。

## 12. 开源组件版本基线

技术路线已冻结为 Java/Vue + RuoYi-Vue。M0/M1 需要补齐具体版本号、许可证复核结果和下载来源。

| 组件 | 候选 | 版本 | 许可证 | 用途 |
|---|---|---|---|---|
| 后台框架 | RuoYi-Vue 体系 | 待定 | 待确认 | 生产主基座 |
| 后端框架 | Spring Boot 3 | 待定 | 待确认 | 业务 API |
| 前端框架 | Vue 3 | 待定 | 待确认 | PC 后台和 PWA |
| 数据库 | MySQL 8.4 LTS | 待定 | 待确认 | 业务数据 |
| 文件存储 | NAS 优先，S3 兼容服务备选 | 待定 | 待确认 | 视频附件 |
| 视频处理 | FFmpeg | 待定 | 待确认 | 视频截取 |
| 二维码识别 | ZXing / BarcodeDetector | 待定 | 待确认 | PWA 扫码 |
| 图表 | ECharts | 待定 | 待确认 | 报表图表 |
| Excel | EasyExcel / SheetJS | 待定 | 待确认 | 导入导出 |
| 审批引擎 | Flowable/Camunda | 二期待定 | 待确认 | 二期复杂审批 |
| ERP 参考 | ERPNext/Frappe、Odoo | 不进入生产 | 待确认 | 模型参考 |

要求：

- 每个组件必须记录版本、许可证、下载来源、用途。
- 企业版或商业授权能力必须单独标识。
- 版本升级必须经过测试环境验证。

## 13. 备份与恢复

### 13.1 备份范围

- 业务数据库。
- 上传附件。
- 视频片段。
- 配置文件。
- 标签模板。
- 报表模板。

### 13.2 备份策略

| 对象 | 建议 |
|---|---|
| 数据库 | 每日全量备份 + binlog 增量，关键阶段增加手动备份 |
| 视频附件 | NAS 快照或文件级增量备份，按保存周期归档 |
| 配置文件 | 每次变更后纳入版本记录 |
| 模板文件 | 版本化保存 |

恢复目标：

| 指标 | 试点目标 | 正式目标 |
|---|---|---|
| RPO | 24 小时 | 15-60 分钟 |
| RTO | 1 个工作日 | 4 小时内 |
| 恢复演练 | 试点前 1 次 | 每季度 1 次 |
| 备份保留 | 30 天 | 90 天以上 |

### 13.3 恢复演练

试点前至少完成一次恢复演练：

- 从备份恢复数据库。
- 恢复附件和视频访问。
- 验证追溯链路可打开媒体文件。
- 验证用户和权限正常。

## 14. 变更控制

### 14.1 变更流程

1. 提出变更。
2. 判断变更等级。
3. 评估影响：业务、数据、权限、库存、报表、硬件。
4. 审批。
5. 测试环境验证。
6. 发布到试点或生产。
7. 记录变更结果。

### 14.2 必须审批的变更

- 损耗率。
- 计件单价。
- 库存状态。
- 编码规则。
- 角色权限。
- 视频保存周期。
- 数据库结构。
- 开源组件版本。
